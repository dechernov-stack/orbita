# web — клиент ИС (ADR-010: TypeScript, React, CesiumJS)

**В клиенте нет расчётов.** Свёртка бюджета, нормировка розы KPI, критерий
успеха, состояние верификации, глубина в дереве и подпись единицы приходят
с сервера посчитанными (`core/out/ScreenViews.kt`). Пересчёт любого из этого
здесь создал бы вторую реализацию правила — и она разошлась бы с серверной
молча: обе показали бы число, просто разное.

Инвариант проверяется механически: `tools/validate_web_no_math.py` запрещает
арифметику и сравнения над величинами модели, а также таблицы соответствия,
дублирующие серверные. Проверка входит в `ci/checks.sh`.

## Запуск

```bash
npm ci
../gradlew :core:com:demoServer   # API с наполненной моделью, порт 8080
npm run dev                       # клиент на 5173, /api проксируется на 8080
```

## Проверки

```bash
npm run typecheck        # типы клиента против форм ответов API
npm run check:screens    # экраны на реальных данных API (нужны demoServer и dev)
```

`check:screens` открывает страницу браузером и проверяет то, чего не видно
по ответу API: строки отрисованы, отступ дерева виден, превышение бюджета
покрашено и показано величиной, карточка открывается, консоль чиста.
