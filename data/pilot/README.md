# Затравка «Ротор-Л» (data/pilot)

Материал замера плотности интерфейса (задание «прогон до KDP B», §3.6):
проект `PJ-0100` с 41 требованием, нуждами, сервисами, ConOps, составом
системы, рисками и технологиями. Нить трассировки сшита: у каждого
требования есть источник и распределение (проверяет `PilotSeedTest`).

Загрузка одним действием на пустой стенд:

    curl -sS -X POST http://localhost:8080/api/import/objects \
      --data-binary @data/pilot/pilot.json

Пачка сама несёт проект-контейнер и автора; порядок объектов в файле
не важен — его разрешает сервер (ADR-024). Это затравка для замера,
не настоящий проект: сотни требований приёмки приходят из блока E.
