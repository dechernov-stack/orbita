## Решения и расхождения

- «Библиотека» как область LIB (не проект); ссылки проект → библиотека —
  законное исключение ADR-022. Основание требования теперь может указывать
  на норматив полки А1 (traces_up + NR) — «основания на А1 не режутся».
- Идентификаторы пачки фрагмента — локальные метки; применение выпускает
  новые id и ремапит внутренние ссылки (id глобально уникальны, TZ-MOD-007).
- Файлы-вложения (А3/А4/В2) система не хранит — карточка с текстовой
  выжимкой; blob-хранилище — вопрос владельцу.
- Кнопки «Сохранить как шаблон» на экранах — конвейером по эталонам;
  сервер (preview/save/apply) готов и покрыт тестами.
