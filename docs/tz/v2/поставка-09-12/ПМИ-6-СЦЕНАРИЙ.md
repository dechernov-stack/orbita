# ПМИ-6 — прогон с нуля на знаниях v2 (корпус → синтез → сцены → точки → Phase A)

12.09.2026. Заменяет ПМИ-5. Проход владельца на новом проекте после
исполнения пакета «Знания v2». Артефакты — снимок по имени шага;
замечания — в журнал (форма прежняя: `З-NN · шаг · экран · роль · тип ·
суть · предложение · снимок`), пачками после каждой части. Ничего не
писать руками там, где предложение есть из поля.

## Предусловия (Code, до старта)

- пакет «Знания v2» исполнен целиком; `knowledge_v2` включён по
  умолчанию для новых проектов; блокеры З-01…З-04 закрыты;
- полки загружены (все, включая FAD/FA, SMA, Project Plan, нормативы,
  процессы Романова); диск ≥ 15 ГБ; ключ модели; `walkthrough on`;
- материалы в проекте нет — загружаются в проходе; файлы на стенде:
  записка миссии (md), «Анализ идей IoT студенты» (docx), ТЗ МКУСС ПД
  (docx), даташит платформы (PDF), результат исследования «Приморье»
  (md — из внешнего контура, владелец запускает промпт заранее);
- три учётки (локально) или «выступить от имени роли» (216);
  тег `пми6-старт`, копия базы.

**Токены.** Живые вызовы: атомизация — по одному на каждый из пяти
документов; синтез — по запуску (ожидаю 3–4 за часть 1); сверки
ручного ввода — по срезу; рендер — три раздела. Счёт — в журнале ИИ.
