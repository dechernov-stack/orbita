# Перечни истины без русских слов — одной таблицей (26.09)

Ответ владельца на вопрос §7 шипа 5: «список перечней без русских слов —
пришлите одной таблицей, слова дам диффом». Здесь — каждое поле-перечень
истины схем (`СХЕМЫ-ПОЛЕЙ-V2.yaml`), у значений которого нет метки в
`enum_labels`: код значения сегодня виден на экране как есть либо экран
прячет поле. Значения, уже написанные по-русски, в таблицу не входят;
обозначения-коды (класс обслуживания «A′», стандарт «NASA-7120») — входят:
решите, оставлять ли их кодом.

Слова — в колонку «слова» (код → слово через «·») или сразу диффом в
`enum_labels` истины (`вид.поле: {код: слово}`). Таблица собрана из истины
на коммите этого файла; перечней без слов — **63**.
