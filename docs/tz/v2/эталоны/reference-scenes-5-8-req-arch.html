Грани по ступеням: закрытые — зелёным, текущая — «нужно к SRR: 2», будущие — серым с точкой. Пустая грань показывает, что ожидается и к какой точке.

Разрывы ступени SRR

  • стандарты применимости → ECSS-E-ST-40C
  • поставщик/ответственный
  • функции распределены
  • стыки названы
  • ресурсы ±30 %

Правила эталона: реестр — ровно шесть колонок, остальное в карточке под строкой группами; линт и TBR — чипами и счётчиками, не строками; носитель — пикер по природе (узел · стык · цепочка); сравнение вариантов — без итогового балла, отсеянный назван с порогом; карточка компонента — лестница ступеней сверху, грани сеткой, пустая грань — с точкой ожидания.
