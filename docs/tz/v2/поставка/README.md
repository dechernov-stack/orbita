# Поставка владельца — файлы вне репозитория

Здесь лежат документы, которые владелец присылает на разбор: записка
миссии, аналитика, ТЗ смежных разработок. В git они **не идут** —
репозиторий публичный, а это содержание конкретного проекта.

Что нужно для прогона поля знаний:

| Файл | Откуда | Зачем |
|---|---|---|
| `ЗАПИСКА-МИССИИ-IoT.md` | поставка владельца 06.09 (`1.zip`) | полная записка, 12 разделов: источник фактов сцен 2–6 |

Загрузка на стенд — `POST /api/v2/materials` типом `mission_memo`,
затем `POST /api/v2/intake/atomize` с заданием «разбери по сущностям».
