# Сцена 9 · операционные сценарии Pre-A — три штуки, вставить как есть

Участники — из состава (узлы), сторон и внешних систем. Достаточно
двух для выхода сцены; третий — тревога, он нужен ConOps §5 и MCR.

## 1. Штатная доставка телеметрии (класс B′, накопление и сброс)

| Участник | Что происходит |
|---|---|
| Терминал абонентский (датчиковый/мобильный) | накапливает пакеты телеметрии, ждёт пролёта по альманаху |
| КА (БРТК-S) | принимает пакеты в зоне видимости, хранит на борту |
| КА (БРТК-F) → Шлюз (GW) | сбрасывает накопленное при пролёте над станцией |
| ЦОД (DC) | принимает, маршрутизирует, ведёт SLA |
| ГАИС «ЭРА-ГЛОНАСС» (внешняя система) | получает регуляторную телематику в составе п.3б |
| Заказчик (сторона) | видит объекты на своей платформе |

## 2. Нештатный: потеря наземного покрытия (гибридный терминал)

| Участник | Что происходит |
|---|---|
| Терминал мобильный (гибридный) | теряет сеть подвижной связи, переключается на спутниковый канал |
| КА | принимает пакеты первым доступным пролётом |
| ЦОД | помечает поток «резервный канал», сохраняет непрерывность SLA |
| Терминал | при возврате наземной сети досылает пропущенное и возвращается на наземный канал |
| Ространснадзор (сторона) | не видит разрыва в регуляторной телематике |

## 3. Тревога (класс A′, приоритет)

| Участник | Что происходит |
|---|---|
| Датчик / терминал | формирует тревожный пакет с приоритетом |
| КА | принимает при первом пролёте, отдаёт вне очереди |
| ЦОД | маршрутизирует тревогу диспетчеру за время класса A′ |
| МЧС / региональная служба (сторона) | получает тревогу и подтверждает приём |
| ЦОД | фиксирует время доставки для SLA |

Правило в пачку: при входе в сцену 9 сценарии **предлагаются** из
сервисов проекта и цепочек полки Arcadia — кнопкой, а не руками.
