# Задание Code — знания v3: промпты, документ как источник, массовый приём

15.09.2026. Идём вперёд: цель — **пройти сцены 2–8 без ручного набора
и без прокликивания по одному**. Пять шипов по зависимостям, после
каждого — короткая проверка владельцем (10 минут, не полный проход).
Источники: `ПРОМПТ-ФОРМИРОВАНИЕ-V2`, `ОБЗОР-ПРОМПТА-ФОРМИРОВАНИЯ`,
`РЕШЕНИЕ-ДОКУМЕНТ-ПЕРВИЧЕН`, `РЕШЕНИЕ-ПРИЗМА-И-ПРИМЕНИМОСТЬ`,
`ТРЕБОВАНИЯ-К-ЗАПИСКЕ-МИССИИ`, `ОНТОЛОГИЯ-ФОРМИРОВАНИЯ.yaml` (призма,
роли, allowed_roles, opportunity), `СХЕМЫ-ПОЛЕЙ-V2.yaml` (96 видов).

## Шип 1 · Промпты — блокер всего (≈1 день)

1. **Разбор**: факты только структурой — `субъект · предикат · объект ·
   значение с единицей`, вид обязателен, якорь обязателен. Нет
   предиката — факт не выпускается (сигнал разбору, не синтезу).
2. **Формирование** — по `ПРОМПТ-ФОРМИРОВАНИЕ-V2`: факты записями с
   полями; предикаты и анти-примеры из онтологии; понятия по сцене с
   порядком «стороны → нужды → цели/сервисы»; ссылки `{"code"}` /
   `{"ref"}`; принятое — с полями вердикта; потолок и отбор по рангу;
   самопроверка перед выводом.
3. **Формат — схемой**, не текстом: structured output / tool use, чтобы
   правка инструкций не ломала вывод (случай 15.09).
4. **Призма в обоих промптах**: замысел, границы («чего не строим»),
   сервисы, цели, рамки Р — из документа роли `charter`.

**Мера.** Фикстуры без стенда: записка → ≥ 14 сторон, ≥ 14 оценок
интереса, ≥ 6 рамок нехватки; синтез сцены 3 → 14 сторон / 43 нужды
(`ПАКЕТ-СТОРОНЫ-И-НУЖДЫ`); Приморье → 8 сторон, 0 нужд из ролей, 0
целей; ПП 2216 → 22 факта, 4 из п.3б, 3 порога полем
(`РАЗБОР-ПП-2216`); повтор на том же срезе — тот же набор.

## Шип 2 · Документ как источник (≈2 дня)

- **Роль документа** при загрузке (charter · tor · regulatory ·
  context · supplier · heritage), предлагается разбором, правится
  человеком; **charter в проекте один** — второй отвергается с именем
  первого.
- **Требования к уставу**: при загрузке charter — проверка 12 пунктов
  (`ТРЕБОВАНИЯ-К-ЗАПИСКЕ-МИССИИ`) и **карта пробелов**: что есть,
  чего нет, какая сцена этим закрывается.
- **Досье документа** в библиотеке проекта: оригинал · канон ·
  **резюме 3–5 строк** (порождается при разборе) · роль · ранг ·
  версия · вклад (фактов по видам, принято/учтено/отклонено, сущности
  со ссылками) · полезность.
- **Два взгляда**: «документ → что из него вышло» и «сущность → на чём
  стоит» (якоря и роли источников).
- **Изоляция и откат**: у фактов `parse_run`; «Откатить вклад
  документа» снимает его факты и образованное только из них; сущности
  с другими основаниями остаются с пометой. Переразбор — новый прогон,
  старое `superseded`, дублей нет.

**Мера.** Второй устав — отказ; карта пробелов на нашей записке;
досье записки: резюме, вклад, 40+ сущностей со ссылками; откат вклада
Приморья — постановка из записки цела.

## Шип 3 · Массовый приём — главный по удобству (≈2 дня)

Сотня предложений не прокликивается по одному. Экран «Предложения»:

1. **Группировка и порядок**: по понятию (стороны · нужды · цели ·
   ограничения) и вердикту; **сверху — «требует внимания»**:
   противоречия, без обязательной связи, уверенность ниже порога,
   источник сомнительного ранга. Остальное — «обычные».
2. **Выбор**: чекбоксы, «выбрать группу», диапазон Shift-кликом,
   инверсия; клавиши: `↑↓` навигация, `Space` выбрать, `Enter`
   раскрыть карточку, `A` принять выбранные, `R` отклонить, `L`
   отложить.
3. **Умные наборы** одной кнопкой: «все `new` из обязательных
   источников», «все с уверенностью ≥ 0,8», «всё, кроме требующих
   внимания», «только дополнения к принятому».
4. **Предпросмотр последствий** до нажатия: «выбрано 43 из 118 →
   появится 12 сторон и 31 нужда; 4 нужды получат сторону; 2
   противоречия останутся нерешёнными».
5. **Одна транзакция + «Отменить пакет»**: приём пачкой обратим целиком
   (та же механика, что откат прогона), отмена доступна и позже — из
   журнала приёмов.
6. **Требующие внимания в массовый приём не попадают никогда** —
   только поштучно, с причиной на экране.
7. **Прогресс и возврат**: «рассмотрено 118 из 130, отложено 12»;
   отложенные не мешают воротам, но видны счётчиком.
8. **Приём дёшев и обратим**: принятое правится на месте (уже есть) и
   снимается массово тем же экраном — «снять принятие» для выборки.
   Эксперт может смело брать много и чистить позже.

**Мера.** 118 предложений принимаются за ≤ 5 действий; противоречия
не попали в пакет; «Отменить пакет» возвращает состояние; массовое
снятие 20 нужд — одно действие; клавиатура проходит весь экран без
мыши.

## Шип 4 · Каталог и библиотека (≈1 день)

- Загрузка **нескольких файлов/каталога** сразу: очередь, у каждого
  своя карточка и роль (предложена, правится до запуска), разбор по
  очереди, **сводка партии**: документов, фактов, противоречий,
  дублей источников.
- **Библиотека проекта** хранит оригиналы вместе с разобранным;
  документ (кроме устава) **берётся в другой проект вместе с фактами**
  — без повторного вызова модели.

**Мера.** Каталог из 6 файлов — одна очередь и одна сводка; норматив
из библиотеки взят в новый проект, вызовов модели 0.

## Шип 5 · Применимость (≈1 день, после прохода сцен 3–6)

`opportunity`: чужая нужда/цель → наши сервисы → вердикт (закрываем ·
частично · не наш профиль · нужна доработка) · чего не хватает ·
предложение эксперту. Матрица применимости на Постановке; в карточке
цели — внешние обоснования.

**Мера.** Приморье даёт ≥ 4 возможности, из них ≥ 1 «не наш профиль»
со ссылкой на границу устава; ни одной цели.

## Правила

Красный CI — стоп. Правка промпта проверяется фикстурой до выката.
Живой вызов — только там, где проверяется живой контур; фикстуры —
без модели. Стенд под владельцем не трогать без слова. Отчёт —
таблицей «шип · сделано · тег · вопросы», первая строка — состояние CI.
