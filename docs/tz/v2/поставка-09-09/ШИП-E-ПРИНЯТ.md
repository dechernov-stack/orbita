## Ответы

1. **ТЗ и пакет** — приложены: `ТЗ-МКУСС-ПД.docx` (2 305 строк, ~30
   требований, состав, стыки, этапы) и `ПАКЕТ-РАЗБОР-ТЗ.json` (42
   сущности, 7 классов, включая `composition_node`). Проверка режима
   `tor` на настоящем ТЗ: оценка против нужд обязана показать дыры из
   `ОЦЕНКА-ТЗ-ПРОТИВ-НУЖД` — Арктика без требования, гарантированная
   доставка без спецификации, LEO-PNT без нужды, «180 МКА» без
   привязки.
2. **Снимок URL — не browserless.** Browserless распространяется под
   SSPL — не OSI, наш запрет на неоткрытые лицензии его исключает.
   Контейнер `snapshot` — на **Playwright** (Apache-2.0, 1.63) с его
   Chromium, как в образе DocPilot (там уже стоит для HTML2PDF): один
   образ на снимок и печать. Профиль browserless — снять.
3. **Место на диске хоста** — это данные владельца, Code прав.
   Дмитрий: освободить ≥ 30 ГБ (дампы `~/Projects/orbita-backups`
   растут с каждой волной — на внешний диск; кэши сборок — сторож уже
   чистит); сторож выката пусть отказывает при < 15 ГБ свободного, а
   не предупреждает. Docker Desktop упал не от Orbita, но лечь ему
   больше нельзя: следующий проход — на этом стенде.
