# Онтология фазы Pre-A — словарь, связи, шаблоны, инварианты

Правило: **сущность существует только в своей сцене, живёт только по
своему шаблону и связана только объявленными связями.** Всё, чего нет в
этом словаре, в Pre-A не вводится (эксперт-режим не в счёт).

## 2. Связи — граф (что на что ссылается)

- Нужда **→** Стейкхолдер (носитель, 1); Цель **→** Нужда (≥1); Сервис
  **→** Нужда (≥1) и **→** Класс обслуживания (1).
- Требование **→** источник: Цель | Нужда | Ограничение (≥1);
  Требование **→** Носитель (1, узел состава); Требование **→** Метод
  верификации (1, допустим TBD).
- Вариант **→** Состав (узел «КА» ×N); Метрика **→** Вариант; Базовая
  концепция **→** Вариант (1) + отклонённые (≥0).
- Сценарий **→** функции/узлы базовой концепции; ConOps **→** Сценарии
  (≥1); Требование сценарное **→** Сценарий.
- Технология **→** Узел (1); Риск **→** Узел | Сцена (≥1); Оценка **→**
  WBS-пакеты **↔** Узлы (пары).
- Документ **→** снимок сущностей сцен (не копия); Точка **→** критерии
  **→** сцены; Замечание **→** Сцена.
- Ничего не ссылается *вперёд*: сущность сцены N не может зависеть от
  сущности сцены > N.

## 4. Инварианты — что делает кашу невозможной

1. Нужда без стейкхолдера не существует. 2. Цель без показателя и года —
не цель. 3. Ограничение без кода Р — не ограничение. 4. Сервис без
нужды и класса — не сервис. 5. Базовый вариант без обоснования и
отклонённых — не базовый. 6. Требование без носителя — не требование;
без источника — не требование. 7. ConOps без сценариев — не ConOps.
8. Технология без TRL — запись, не оценка. 9. Риск без владельца и
срока-точки — заметка, не риск. 10. Оценка числом, а не диапазоном, —
ложь точности. 11. Документ, не собранный из сцен, — не документ
проекта. 12. Ссылка вперёд по сценам запрещена. 13. Переход фазы —
только решением KDP-A.

## 5. Чего в словаре Pre-A нет — и почему

Системных требований, интерфейсов как носителей, SEMP, архитектуры
Arcadia (LA/PA), функций как отдельного слоя, заданий Ганта по шагам —
это Phase A. В Pre-A они не показываются; словарь Phase A — отдельный
документ следующего дня раздумий.
