# Code · ответ на развилку §2.1 — путь ScenarioProposer: нет. Один путь, основание шире

**Самостоятельный проповедник на каждого помощника не берём.** Четыре
помощника × свой `/propose`+`/accept` = четыре приёма, у каждого своя
недоделанная копия того, что у сверки уже есть и проверено владельцем:
массовый приём (шип 5 §1.4), отклонить · отложить с причиной, «Отменить
пакет», журнал и кэш по отпечатку среза, засчитывание условиям сцены,
вкладка «Предложения» с отбором по прогону — и главное, **вердикт по ключу
идентичности**: ворота из задания «дубль функции — augment, повтор стыка —
confirm» и есть сверка. Самостоятельный путь заставил бы писать её заново
четыре раза. `ScenarioProposer` — исключение, которое надо будет свести в
общий путь, а не образец.

Развилка — не в модели, а в коде: основание-факт обязательно у
`FormationProposal`, истина этого не требует (`proposal.items[].anchors?`,
`source: {material?, prompt?, external?}`), а `requirement.source.kind` уже
знает `requirement · goal · need · constraint`. Расширяем основание.

## Диф `СХЕМЫ-ДИФФ-28-09-b-ОСНОВАНИЕ-МОДЕЛЬ.patch` (к `59baa4e`)

* `formation.document_roles.model` — картина проекта как «роль»: основание
  — сущность или разрыв, не факт; целей, сервисов, сторон не порождает.
* `formation.model_basis_rule` — основание одно из трёх: **факт · сущность ·
  разрыв**; любое — одной сверкой и одним приёмом; при приёме основание-
  сущность ложится в `requirement.source`, разрыв — в ссылку риска.
* `concepts.requirement.allowed_roles += model` (деривация вниз, `derives`
  обязательна, доли бюджета ≤ родителя); `concepts.risk.allowed_roles +=
  model` (риски из разрывов).
* **Новые понятия** `function · exchange · interface · parameter` — `from`,
  `fields`, `must_link`, `identity`, `conflict_on`, как у прочих; ворота из
  таблицы §2 задания записаны в `must_link`/`note`.

## В коде

* `Basis` — закрытый тип из трёх: `Fact(factId, anchor)` ·
  `Entity(kind, code, anchor?)` (anchor — поле или шаг сценария) ·
  `Gap(kind, node, facet, point)`. Сверка и приём принимают любой;
  предпросмотр и «основания» в карточке предложения показывают каждое
  словами со ссылкой «к месту».
* Помощник = **срез картины → промпт → ответ по схеме понятия → предложения
  в прогон синтеза** (`synthesis_run.trigger = manual`; помощника отличает
  `package_kind` — строкой полки `package_kind`, не кодом). Кнопка ведёт в
  «Предложения» с отбором по прогону.
* 2.4 (анкета из паспорта) — основание-факт, путь чтения, как вы и сказали.
* `ScenarioProposer` — после §2 свести в тот же путь, долгом в NEXT.md.

Порядок прежний: §2.1 образцом (с тестом на отказ каждого ворот), затем
2.2–2.5 тем же каркасом. Без выката.
