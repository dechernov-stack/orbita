## 1. §2.2b — обмены в том же пакете, что функции, а не вторым проходом

Обмен ссылается на функции, которых до приёма нет. Не делите на «сначала
примите функции, потом запустите обмены»: владелец получит два прогона и
двойной приём там, где работа одна.

* Модель отвечает функциями **и** обменами за один вызов; обмен ссылается
  на функцию **локальным ключом предложения** (или кодом уже принятой).
* Приём пакета — **функции первыми**, затем обмены: локальный ключ
  разрешается в код только что заведённой функции.
* Функция-источник или приёмник отклонена или отложена → обмен **не
  отказ**, а «отложено: функция-источник «…» не принята» — вернётся, когда
  примут.
* Ворота из понятия `exchange`: оба конца есть (предложены в пакете или
  уже приняты); повтор по ключу `source_function+target+payload_core` —
  augment.

Тест: пакет из 3 функций и 2 обменов — примут все; отклонена одна функция
— её обмен отложен со словами, второй принят.
