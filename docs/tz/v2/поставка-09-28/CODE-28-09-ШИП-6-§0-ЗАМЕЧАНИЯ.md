# Code · шип 6 §0 — три замечания по ходу (28.09)

§0.1–§0.3 приняты по коммитам `21cd84e`, `8287208` и отчёту. Три правки,
прежде чем идти в §1:

## 1. Полка единиц потеряла написания — диф `СХЕМЫ-ДИФФ-28-09-НАПИСАНИЯ-ЕДИНИЦ.patch`

Справочник UR-9001 несёт **176 написаний** («минут», «часов», «килограммов»,
«км»), полка — по одному `name` на единицу: истине некуда было их положить.
Без них чтение и `Normalize` не узнают «не более 180 минут» в тексте
документа. Диф добавляет `unit.spellings: str[]` — перенести все написания
источника; из них же сид словаря берёт синонимы терминов класса `unit`
(одна истина, словарь — производный).

Попутно по той же полке:
* **`pcs` назван «КА».** Счётная единица — «шт»; «КА», «аппаратов»,
  «терминалов», «устройств», «станций» — её написания. Тогда «устройств» и
  «терминалов» из документов перестанут быть «вне справочника».
* **Латиница в `name` у 11 единиц**: `Pa` → Па, `bar` → бар, `Gy` → Гр,
  `rad_dose` → рад, `MRUB/kg` → млн руб/кг, `kUSD/kg` → тыс долл/кг,
  `man_month` → чел-мес, `man_h` → чел-ч, `mission_class` → класс миссии;
  `TRL` и `U` — оставить. Сторож генератора: `name` без латиницы, кроме
  списка устоявшихся (TRL, U), и не равен `symbol`.
* **183 → 82.** Прежний `/v2/units` отдавал 183 — проверить на копии базы
  стенда, что каждая единица, стоящая в записях (требования, параметры,
  факты, бюджеты), находится в полке по имени или написанию; остаток —
  списком в NEXT.md.

## 2. Словарь: актор `null` не должен значить «все роли»

§0.3: «вызовы без актора → все роли → проходят» — это открытые ворота по
умолчанию. Ворота закрыты по умолчанию: нет актора — 403; тесты передают
актора явно (ведущий СИ). И **служебная личность (ADR-071) не хозяин
словаря**: словарь класса миссии общий для всех проектов, решения по нему
принимает человек — как ворота точки по ADR-072. Тест на оба отказа.
