# Code · диф бюджета — `СХЕМЫ-ДИФФ-29-09-b-БЮДЖЕТ.patch` (к `bb16d9b`)

«Не мягче» (`bb16d9b`) принят. Поправка моя: в прошлой записке я написал,
что истина уже держит `budget.requirement` — это поле события верификации,
у бюджета его не было. Диф:

* `budget.requirement: ref requirement` — **требование-потолок**. Значение
  бюджета — его `measure`, в бюджете не дублируется. Доли — требования со
  связью `derives` на потолок.
* `budget.reserve_pct: num 0–100` — резерв числом; **текст `reserve_policy`
  не разбирать** — он для документа. Нет числа — потолок без резерва и
  помета «резерв не задан числом».

Оба поля необязательны: у бюджетов без потолка ворот суммы нет, в карточке
бюджета — строка долга «требование-потолок не назван»; в форме бюджета на
A5 — пикер требования (того же узла-корня или выше) и число резерва.

Дальше по вашему плану: бюджетная ветвь (помета при предложении, отказ при
приёме, сумма по всем узлам) + C2-приём (`derives` при приёме) одним
абзацем, затем D. Выката нет.
