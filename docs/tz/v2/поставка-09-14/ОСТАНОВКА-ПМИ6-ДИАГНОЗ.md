# Остановка ПМИ-6 · 14.09 — диагноз по снимку «Постановка»

Остановка правильная: постановка на экране — не постановка, а
свалка. Три дефекта, все в синтезе, и один — в моей поставке.

## 1. Синтез не читает онтологию — нужды из текста роли

ND-0002 «Заказчик/регулятор макрорегиона; курирование Нацпрограммы ДВ
и Плана СМП [П]» — это описание **роли** стороны из моей таблицы
(колонка «значение» у строк класса «сторона»), превращённое в нужду.
По онтологии нужда рождается только из фактов `framing` с предикатами
«нуждается в / требует / не хватает», из `assessment` о стороне с
меткой [П] и из общих нужд §2.1 по субъекту; текст роли —
`stakeholder.role/interest`, никогда не `need.statement`. Цели и
сервисы не сформированы вовсе — «покрытие 0 из 9»: правила `goal`
(quantity + горизонт) и `service` (capability системы) не применены.
**Вывод: `formation` работает не по `ОНТОЛОГИЯ-ФОРМИРОВАНИЯ`, а по
собственной догадке. Нужен тест: записка → ожидание
`ПАКЕТ-СТОРОНЫ-И-НУЖДЫ` (14 сторон, 43 нужды), материал «Приморье» →
ожидание: 8 сторон, 0 нужд из строк роли, программы → `milestone` /
`normative_document`, применения → факты `noted`.**

## 2. Стороны — из любой упомянутой организации

«Президент Российской Федерации», «Правительство Российской
Федерации» стали сторонами, потому что подписали Указ 645 и ПП 2216.
Автор акта — не сторона. По онтологии `stakeholder` образуется только
из `relation`-фактов с предикатами роли **к проекту/системе**
(является заказчиком · оператором · регулирует · поставляет ·
потребляет); нормативы несут регуляторов через `normatives` у уже
заведённой стороны (ГКРЧ, Минцифры, ФСТЭК), не порождают новых.
«Без влияния или силы» у восьми сторон — следствие того же: у
случайных сторон нет предикатов, из которых выводится влияние.

## 3. Ранг «сомнительный» не удержал

Материал исследования загружен рангом «сомнительный»; его строки
стали принятыми сущностями (ND-0002…0008 в покрытии, стороны в сетке).
Правило поля: из `doubtful` — только предложения с пометой «источник
не подтверждён», и ни одно не принимается пакетом «принять всё» без
подтверждения источников. Здесь либо ранг не дошёл до синтеза, либо
акцепт прошёл без проверки ранга.

## 4. Моя доля — формат результата исследования

Колонка «Значение» у строк класса «сторона» несла текст роли — синтез
взял его как утверждение. Формат исправлен:
`ИССЛЕДОВАНИЕ-ПРИМОРЬЕ-ЦИКЛ1.md` переложен в явные поля — `класс ·
субъект · роль · интерес · масштаб · источник` для сторон и `класс ·
субъект · утверждение · величина · источник` для остального; правило
для промпта исследования — тот же формат.
