# Волна 0 — принята. Ответы и поправки (07.09.2026)

## Принято

Тег `v2-wave0`, 1267 + 30 зелёных, ноль провалов. Отмечу три решения
Code как правила v2:

1. **Архитектурный тест читает зависимости из самих `build.gradle.kts`**
   — второй карты модулей нет, разойтись нечему. Konsist в этом
   случае не нужен; пункт ТЗ снимаю. Условие: тест обязан ловить и
   *чтение чужой схемы БД* (SQL/Exposed-ссылки на таблицы другого
   модуля) — если это по сборочным файлам не видно, добавить проверку
   по коду в волне 1.
2. **`SpineTest` по существу**: задача точки не существует, пока
   условие не выполнено, и появляется сама — правильная семантика
   sentry; домена в движке нет.
3. **Загрузчик полок со сторожем отпечатков и внятным отказом** — «старый
   стенд не знает видов v2» вместо тихого 500.

## Поправка поставки — моя ошибка

Групповые записи «account · role · right» и «typical_requirement ·
typical_risk · stakeholder_profile» разведены на **шесть видов со
своими полями**; `СХЕМЫ-ПОЛЕЙ-V2.yaml` — 90 видов, кодов с пробелом — 0.
Поля учётки (логин, имя, роли), роли (права, участие по стадиям), права
(код, область) — разные, как Code и предположил. Перегенерируйте схемы.

## Два вопроса, держащих волну 1 — рекомендации владельцу

1. **Стандарт по умолчанию — NASA-7120** для новых проектов: весь
   контент, регламенты и полки написаны в его именах; РК-11КТ — как
   псевдонимы рядом (в скобках) и как выбор в паспорте проекта для
   заказчиков, которым нужны их имена. Стандарт — свойство проекта,
   меняется без миграции (id точек те же).
2. **Порог «Плана работ фазы» — план хотя бы у первой доступной
   задачи**; остальные — помета «план не задан» на ленте, к SRR —
   разрыв. Строгий порог «у всех» делает сцену непроходимой в первый
   день фазы.

Оба — на подтверждение владельцу; до подтверждения Code кодирует
рекомендации за флагом.
