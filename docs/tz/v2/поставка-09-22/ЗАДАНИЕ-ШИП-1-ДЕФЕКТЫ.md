## 1.1 · Права (блокер безопасности)

- Сессия без роли — **не** «все роли»: без роли — 401/403 на любую
  запись; на стенде в режиме stand роль берётся из селектора, на 216 —
  из учётки и «выступить от имени».
- Экран точки: кто фиксирует (роль и имя), кто согласует; кнопка
  фиксации **видна только той роли**, которая может; остальным —
  строка «фиксирует DA · Чернов Д.».
- Тест на отказ: инженер → 403 с именем роли; DA при блокирующем → 409
  с критерием; сессия без роли → 401.
