## 2 · Дизайн (≈2 недели, параллельно с 1 с третьего дня)

По `ДИЗАЙН-НАПРАВЛЕНИЕ`, `ДИЗАЙН-ПРИНЦИПЫ-V2`, `РЕЖИМЫ-РАБОТЫ-ДВУХ-РОЛЕЙ`,
эталонам и промпту Stitch-2. Из макета Stitch-2 (пришёл один экран,
«Проекты») **берём**: компактную шапку с проектом, фазой и точкой;
одно меню пользователя аватаром; две колонки карточек-строк.
**Не берём**: декоративные строки («PORTFOLIO_REGISTRY // V.04»,
«СТАТУС СИНХР: ОК», «SEC_DRAFTS_EMPTY_0x00»), капслок и усечение в
рейке («ПОСТАНОВ…»), сетку-бумагу в пустом состоянии, усечённые имена
проектов — это ровно тот шум, который мы вычищаем.

| Экран | Что делаем | Эталон |
|---|---|---|
| Шапка и рейка | 40 px: проект · фаза · точка; всё личное — в меню; рейка с полными подписями | Stitch-2 + `reference-design-direction` |
| Проекты | две колонки, карточки-строки, пустое состояние строкой | Stitch-2 |
| Новый проект | форма с датами трёх точек, умолчания от старта | промпт §2 |
| Работа | сцена в теле: лента слева, поверхность справа; сцена из шапки убрана | `reference-process-surface`, промпт §3 |
| Карта фазы | ось времени по неделям, три дорожки, станции на окнах, ответственные, точки на датах, линия «сегодня» | промпт §4 |
| Мостик · Моя работа | два входа по ролям | `reference-bridge-and-mywork` |
| Мероприятие инженера | одно мероприятие во всю ширину, рейка с подписями | `reference-activity-engineer` |
| Состав | дерево-таблица, правка на месте, «взять из полки» в дереве | промпт §5 |
| Требования | виды (таблица · иерархия · документы · матрица), сортировка, чипы, группировка, карточка по эталону | `reference-scenes-5-8-req-arch`, промпт §6 |
| Библиотека | каталог полок с «Взять в проект…» | промпт §7 |
| Постановка | сетка «влияние × сила» с предложенной силой, карточка стороны | промпт §8 |
| Приём предложений | массовый приём полный: умные наборы, клавиатура, массовое снятие | `ЗАДАНИЕ-CODE-ЗНАНИЯ-V3` шип 3 |

действия, ноль лишних; специалист проходит поручение без карты;
