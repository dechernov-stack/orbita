## Решения, которые прошу утвердить

1. **Связь — объект** (`link`, № 42) с видом из реестра и обязательным
   обоснованием; не поле «relations» внутри сущности.
2. **Показатель — не сущность**, а структура `{op, value, unit}` внутри
   цели/требования/метрики; единица — ссылка на `unit`.
3. **Матрицы, готовность, прогресс — виды-проекции**, не хранятся.
4. **Анкета** — шаблон в L0 (`questionnaire`) + экземпляр `data_request`
   на узле/стыке; значения живут в `component.params`.
5. **Предложение службы** — одна сущность `proposal` для всех видов
   пакетов (замысел, урожай, цели, требования, проза…).
6. **Документ — три сущности**: `document` · `section` · `insertion`
   (+ `prose`), не один блоб.

    (интеграционные планы, изготовление) — отдельный реестр позже.
