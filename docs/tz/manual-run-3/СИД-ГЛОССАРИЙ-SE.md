# Сид: глоссарий системной инженерии (выборка Формулирования)

Формат записи: термин RU · EN · определение · источник «NASA SEH App. B /
NPR» (пометкой). Коллизии с существующими терминами решает владелец —
наш термин главнее, SEH примечанием.

| Термин RU | EN | Определение (кратко) |
|---|---|---|
| Замысел миссии | Mission intent | Сжатая постановка: для кого, что делает, где, к какому горизонту |
| Нужда | Need | Потребность стейкхолдера, ради которой существует миссия; решения не содержит |
| Цель миссии | Goal / Objective | Измеримый результат с показателем и горизонтом, выводимый из нужд |
| Показатель эффективности миссии | MOE (Measure of Effectiveness) | Мера успеха с точки зрения заказчика; не зависит от реализации |
| Показатель характеристики | MOP (Measure of Performance) | Мера свойства системы, обеспечивающая MOE |
| Технический показатель | TPM (Technical Performance Measure) | Отслеживаемый в ходе работ показатель (запас массы, мощности…) |
| Требование | Requirement | Однозначное проверяемое положение «‹носитель› должен …» |
| Обоснование | Rationale | Причина существования требования и его значения; допущения — здесь |
| Трассировка | Traceability | Двунаправленная связь: нужда ↔ требование ↔ элемент ↔ верификация |
| Базирование | Baselining | Фиксация версии под управление конфигурацией; изменение — только с основанием |
| Базовая линия | Baseline | Зафиксированное состояние комплекта под управлением изменений |
| Управление конфигурацией | Configuration Management (CM) | Дисциплина версий, изменений и целостности комплекта |
| Отклонение (адаптация) | Tailoring | Согласованное отступление от нормы с обоснованием и следом |
| Верификация | Verification | Подтверждение «построили правильно» — соответствие требованиям |
| Валидация | Validation | Подтверждение «построили правильное» — соответствие нуждам и ConOps |
| Метод верификации | Verification method | Испытание · анализ · демонстрация · инспекция |
| Концепция операций | ConOps | Описание системы в эксплуатации глазами операторов и пользователей |
| Анализ альтернатив | AoA (Analysis of Alternatives) | Сравнение вариантов концепции по явным критериям |
| Исследование компромиссов | Trade study | Структурированный выбор решения с фиксацией отклонённого |
| Опорная миссия | DRM (Design Reference Mission) | Репрезентативный сценарий, на котором проверяется концепция |
| Сокращение состава | Descope | Заранее определённое отступление объёма при дефиците ресурсов |
| Перечень оборудования | MEL (Master Equipment List) | Сводный список изделий с массами/мощностями и резервами |
| Структура работ | WBS (Work Breakdown Structure) | Иерархия работ проекта; основа оценок и учёта |
| Уровень готовности технологии | TRL | Шкала зрелости технологии 1–9; цель Формулирования — 6 к PDR |
| Запас (резерв) | Margin | Разница между потребным и располагаемым (масса, мощность, ссылка) |
| Стейкхолдер | Stakeholder | Сторона, влияющая на миссию или зависящая от неё; включая поставщиков |
| Жизненный цикл | Life cycle | Фазы Pre-A…F с точками решений между ними |
| Ключевая точка решения | KDP (Key Decision Point) | Решение уполномоченного о переходе фазы |
| Обзор | Review (MCR/SRR/SDR…) | Формальная проверка зрелости по входным/выходным критериям |
| Замечание обзора | RFA / RID | Запрос действия / несоответствие, подлежащие закрытию |
| Независимая комиссия | SRB (Standing Review Board) | Внешняя оценка зрелости на обзорах |
| Продукт точки | Gate product | Артефакт требуемой зрелости к KDP (матрица зрелости) |
| Соглашение о формулировании | FA (Formulation Agreement) | Договор о содержании и ресурсах Формулирования |
| Санкционирование | FAD | Документ, разрешающий Формулирование |
| Оценка стоимости ЖЦ | LCC (Life Cycle Cost) | Полная стоимость от Формулирования до утилизации |
| Пакет данных стоимости | CADRe | Комплект для независимой оценки стоимости |
| Оценка орбитального засорения | ODA | Анализ соответствия нормам ограничения мусора; увод |
| Экспертная инспекция | Peer review | Внутренняя проверка коллегами до формального обзора |
| TBD | To Be Determined | Значение не определено; подлежит замене оценкой с TBR |
| TBR | To Be Resolved | Оценка под подтверждение: что сделать · кто · срок |
| Должен / будет / желательно | Shall / Will / Should | Требование / факт контекста / цель — не смешивать |
