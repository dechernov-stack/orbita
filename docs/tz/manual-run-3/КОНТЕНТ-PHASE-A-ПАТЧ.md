# Патч контента Phase A: разделение задачи 1 (11 → 12 задач)

Решение принято: О1 (развёртывание — шлюз фазы) и О2 (SEMP — параллельный
документ с базированием до SRR) разводятся. После разделения `FS` от
«Развёртывания» — правда по построению, а SEMP получает настоящие
параллели.

**Когда применять:** до раздела Л текущего прогона (Pre-A часть прогона
патч не затрагивает).

## 1. Новые задачи 1 и 2

**1 · Развёртывание фазы** (О1). Вход: решение KDP-A, FA. Место:
паспорт · стейкхолдеры · жизненный цикл. Выход: орг-структура и план
работ фазы (не документ — состояние проекта). Служба: —.
- 1.1 · **Орг-структура и роли** — «кто ведёт фазу; ответственные задач;
  права из реестра» → стейкхолдеры.
- 1.2 · **План работ фазы** — «даты вех фазы и плановые окна задач;
  сроки — только у вех и планов» → жизненный цикл, затем лента.
  Связь: 1.2 `FS` от 1.1.

**2 · SEMP** (О2). Вход: FA, практики центра, NPR 7123.1. Выход: Д2
SEMP — **Baseline до SRR**. Служба: `section_prose` для [С]-разделов.
- 2.1 · **Создать SEMP по шаблону** — «DT-9002; §2, §6–§8 придут
  вставками конфигурации» → документы (преднастроено).
- 2.2 · **Написать связные разделы** — «§3 резюме, §5 организация,
  §10 среда: черновик службой из данных, правка и принятие» →
  документ, действие «Написать связно». `SS` от 2.1.
- 2.3 · **Базировать до SRR** — «переходом; после базирования правка
  только с основанием» → документ. `FS` от 2.1 и 2.2.
