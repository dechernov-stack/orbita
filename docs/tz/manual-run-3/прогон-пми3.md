# Журнал прохода ПМИ-3

Приёмка продукта целиком: пустой проект → KDP-B. Инженер — Дмитрий,
ведущий испытаний — Code. Форма записи: № · вышло · замечание.

**Условия прохода.** Живой стенд `:8080`, версия — тег `mvp-p5-05`.
Живых вызовов службы по умолчанию **ноль**: все ИИ-шаги проходятся
вставкой пакетов, нарезанных из ответов прошлых вызовов. Резерв **[Ж-1]** —
один живой вызов по решению владельца в К4.

Проверено вставкой на стенде до старта: замысел проходит ворота схемы
(четыре поля с якорями); пакет требований — предложено 4, на акцепт
вышло 1, **три отсеяны фильтром** с причиной «значение mop/value без
ссылки на источник». Мера Д1 («фильтр не пропустил порченое») закрывается
этим же пакетом.

### Чего в запасе нет

**Урожай записки (Г2, стейкхолдеры пакетом).** Живого разбора Д2 по
`SD-0006` владелец не делал — нарезать нечего. Промпт разбора сохранён
целиком: `пакеты/ПРОМПТ-Г2-УРОЖАЙ-ЗАПИСКИ.txt` (53 460 знаков, вид
`document_semantic_parse`). Два пути на выбор владельца:

1. отдать промпт внешнему контуру (Claude-проект) и вставить ответ
   пакетом — токены стенда не тратятся;
2. израсходовать резерв **[Ж-1]** здесь, а не в К4.
