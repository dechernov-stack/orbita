# Круг 5 «Работы»: настоящий Гант — план, стрелки, подразделы

## 1. Источник дат: план руководителя вместо высосанных долей

Расчётные доли интервала — фикция, владелец прав. Честный источник:
**плановые даты задач ставит руководитель** — перетаскиванием полосы
или полями в карточке. Это не «ручные длительности-оценки статусов»
(запрет в силе: статусы вычисляются и планов не читают) — это
план-намерение, законный артефакт О1 «план работ фазы»:

- полоса с планом — сплошная, границы = план;
- без плана — тонкая серая «расчётная сетка» (нынешние доли) с явной
  подписью «план не задан»; задать план — потянуть её;
- **план против факта**: вычисленный статус поверх плана — задача не
  стартовала после плановой даты / выход не готов к плановому концу —
  окантовка предупреждения; «цепочка не успевает» считается от планов,
  где они есть;
- сдвиг плана задачи не двигает соседей молча: конфликт со стрелкой
  зависимости — подсветка обеих, решает человек.

## 2. Геометрия: связи — стрелками, не словами

1. Зависимости — **стрелки finish→start** между полосами (SVG,
   ортогональные); слова «ждёт: 4 · Архитектура» уходят из подписей в
   тултип стрелки/полосы.
2. **Вехи — вертикальные линии через всё полотно** с подписями сверху:
   SRR · SDR/MDR · **KDP-B (пропал — вернуть)** · линия «сегодня».
3. Полосы нормальной длины (план либо окно до точки), подпись внутри,
   min 90 px, обрезков 0 (сейчас «в работе · раз…» — обрезан, клятва
   нарушена).
4. Красное — **окантовка**, и только «выход не готов к близкой точке /
   плану»; ждущая задача с далёким дедлайном красной не бывает
   (сейчас 2 и 3 залиты красным — читается как пожар на ровном месте).

## 3. Подразделы: шаги раскрываются в самом Ганте

Строка задачи — шеврон: раскрытие показывает **шаги строками-детьми**
с тонкими полосами внутри окна задачи (последовательные доли — тут
доли честны: порядок шагов задан полкой). Статус шага — вычисленной
галкой; клик шага — рамка ведения на этом шаге. Переброс «на отдельную
страницу» остаётся только как вход в работу, обзор — здесь.

## 4. Вёрстка

Левая колонка (имя + статус строкой) — фиксированная, полотно
скроллится горизонтально; шкала с датами делениями (сейчас — одна дата
в углу); пилюли умирают, полосы — прямоугольники со скруглением по
системе. Легенда — строкой мелким + тултипы.

## Приёмка

- [ ] РП задаёт план задач 1–3 перетаскиванием; полосы сплошные по
      плану; у остальных — серая сетка «план не задан»;
- [ ] стрелки 1→2→3→4→{5,6,7,8,9}, 1→10, 3→11 читаются; слов «ждёт:»
      в подписях нет;
- [ ] три вехи + «сегодня» — вертикалями; KDP-B на полотне;
- [ ] задача 4 раскрыта: 4 шага тонкими полосами, клик шага — рамка
      на нём;
- [ ] задача 2 (ждёт, дедлайн не горит) — не красная; просроченный
      план — окантовка;
- [ ] обрезков 0 (грепом по снимку глазами владельца).

## Ловушки

1. План не влияет на статусы — только на геометрию и предупреждения.
2. Автосдвиг соседей при перетаскивании — запрещён (конфликт решает
   человек). 3. Доли-фикция в подписях не выдаются за план — серое и
   подписанное. 4. Прогресс-проценты на полосах — не заводить.
