# Задача Code: документы — проза, печать, результаты (пачка SEMP)

Источники: `ШАБЛОН-SEMP.md` (v2 + механика) · `SEMP-СВЕРКА-NASA.md` ·
`ЗАМЕЧАНИЯ-ПМИ3-Г.md` (Г-01, Г-02 — той же пачкой). Порядок шипов ниже.

## Шип 0 · Немедленное (проход ждёт)

1. **Печать без служебных ключей**: рендер вставок человеческим текстом
   (поля по-русски, вехи «SRR — 02.09.2026, не проведён», узлы именами);
   сторож печати «латинский служебный ключ» валит выпуск. Чинит И5/Л8
   текущего прохода.
2. Полка описания среды: Orekit — «в резерве», свои расчёты — фактом.
3. **Реестр маршрутов файлом в docs** (имя экрана · заголовок · как
   открывается) — обещан; контент-поставки дальше пишутся по нему.
4. Г-02: счётчик кнопки пачки.

## Шип 1 · Шаблон DT-9002 ред. 2

Структура 11 разделов из `ШАБЛОН-SEMP.md`; **режим раздела [Т]/[С]/[Р] —
поле шаблона** (данными, применимо любому документу полки). Новые
источники: §2 — полка применённых нормативов; §6 — 17 процессов с
tailoring-пометками «вне области»; §8 — TPM из свёрток (запас массы,
запас мощности, тренды замечаний точек).

## Шип 2 · Связный текст (`section_prose`)

Вид пакета с правилами (не привносить; числа из данных с единицей
показа; расхождение с данными — брак; без канцелярита; служебных ключей
в тексте не существует). Действие «Написать связно» на [С]-разделе:
промпт из данных вставок раздела и только их; черновик — на правку,
принятие явное; происхождение «служба, из данных v…». Живой вызов не
обязателен — внешний контур штатно.

## Шип 3 · Устаревание с дифом

Данные вставки изменились → раздел «текст устарел» + **диф полей**
(какие значения разошлись с принятым текстом). Молчаливого
переписывания текста не существует — только пометка и рука.

## Шип 4 · Библиотека → «Результаты»

Третий отдел: карточки выпусков (документ · версия · снимок печати ·
авторы текста из истории правок + выпустивший + дата). Служба автором
не бывает (ServiceAuthors — сторож действует). Существующие выпуски —
миграцией. Действие «обобщить в образец» с карточки результата —
ниткой на полку шаблонов.

## Шип 5 · Г-01 (сопоставление ссылок пакета)

По `ЗАМЕЧАНИЯ-ПМИ3-Г.md`: перемап при нарезке + диалог сопоставления
при вставке с автопредложением; изоляция не ослабляется.

## Ловушки

1. Красота против правды: текст, расходящийся с данными, — брак, а не
   стиль. 2. Автор — человек; служба — происхождение. 3. Режимы
   разделов — данными шаблона, не кодом. 4. Устаревший текст не
   переписывается молча. 5. Изоляцию проектов в Г-01 не ослаблять.
6. Сырые пары в печати — класс, сторож обязателен, точечные правки
   запрещены.
