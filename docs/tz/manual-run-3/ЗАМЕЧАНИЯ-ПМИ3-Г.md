# Замечания ПМИ-3, раздел Г (в пачку Code)

## Г-01 · Пакет между проектами: сопоставление ссылок вместо отказа

Срез пакетов из журнала несёт ссылки исходного проекта — изоляция
честно режет (ADR-022), но инженер остаётся с ручной правкой JSON.

1. **Подготовка срезов**: перемап ссылок на целевой проект по смысловому
   ключу (совпадение формулировки цели/нужды) — обязанность нарезки.
2. **Вставка — ведомое сопоставление**: ссылка на чужой проект — не
   отказ строки, а диалог «ND-0101 (PJ-0001: „…") → нужда этого
   проекта:» с автопредложением по совпадению формулировки и пикером;
   несопоставленное — честно без связи, с разрывом трассировки.
3. Изоляцию не ослаблять: кросс-проектная ссылка по-прежнему не
   записывается никогда.

Мера: срез пакета сервисов из PJ-0001 вставляется в новый проект без
правки JSON руками — сопоставление предложено, инженер подтвердил.

## Г-02 · Счётчик кнопки пачки после автоснятия

После отклонения хвоста кнопка показывает «Принять пачкой (0)» при
12 отмеченных — счётчик не пересчитан. Пересчитывать от фактического
выбора; кнопка с нулём при непустом выборе — невозможна.
