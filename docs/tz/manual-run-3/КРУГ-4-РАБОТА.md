# Круг 4 «Работы»: процесс виден — вид «Схема» и нить потока

## Диагноз

Список = что, Лента = когда, Рамка = как делать. «Как течёт» — не
показывает никто: артефакты движутся между задачами к точкам невидимо,
процесс не читается картиной. Регламент — это поток (О → Д → КТ), а на
экране потока нет.

## 1. Третий вид «Работы» — Схема (карта потока фазы)

1. **Узлы — задачи**: имя, статус цветом (как всюду), люди аватарками,
   чип разрывов; «вы здесь» — подсветка задачи, где открыта рамка.
2. **Рёбра — артефакты именами**: Д2 SEMP, Д3 требования, Д5
   архитектура… — подпись на стрелке; артефакт кликабелен (к документу/
   реестру). Поток «задача → артефакт → задача/точка» — главная
   информация вида.
3. **Точки ◆ — узлы-ворота** с процентом готовности (из готовности,
   не новый счёт); за воротами — следующая фаза свёрнутым облаком.
4. **Раскладка — ярусами** (уже вычислены кругом 2): слева направо по
   потоку, параллельные — колонной; без ручного рисования и без
   сохраняемых координат — схема каждый раз считается.
5. Клик узла → рамка ведения той задачи; клик ворот → готовность.

## 2. Нить потока в рамке ведения

Строка под степпером: «вход: FA ✓ → **[Задача 1]** → выход: Д2 SEMP
(Draft) → ждут: пакет SRR, задачи 2·3» — рамка перестаёт быть туннелем:
видно, откуда пришёл и кого кормишь. Элементы нити кликабельны.

## 3. Живость процесса

На узле схемы — последняя активность («ЧД · вчера»); фильтр «за неделю»
подсвечивает узлы с движением. Процесс отличим от натюрморта одним
взглядом.

## Приёмка

- [ ] Схема Phase A: 11 узлов, рёбра с Д-кодами, три ◆ с процентами;
      «вы здесь» совпадает с открытой рамкой;
- [ ] клик ребра Д2 открывает документ; клик ворот — готовность SRR;
- [ ] нить потока в рамке задачи 1 называет вход, выход и потребителей;
      переходы работают;
- [ ] раскладка не хранится: пересчёт при изменении зависимостей полки
      (тест: изменить вход задачи — схема перестроилась);
- [ ] активность на узлах — человеческие имена (сторож ServiceAuthors
      действует и здесь).

## Ловушки

1. Редактор схемы, ручные координаты, «сохранить раскладку» — запрещены:
   схема — вычисленная проекция, не рисунок. 2. BPMN-нотация и её
   палитра — не тащить: узлы/стрелки/ворота, ничего больше. 3. Схема не
   заменяет ленту — «когда» остаётся у ленты, «как течёт» — у схемы.
