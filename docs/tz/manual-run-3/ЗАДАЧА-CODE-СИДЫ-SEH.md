карта `ЗАИМСТВОВАНИЯ-NASA-SEH.md` (справочно, будущие волны — к своим
точкам ленты).

1. **Правила П13–П20** — в реестр вида `requirements_generation`
   (дописать к действующим; версия правил вверх — отпечаток различает).
2. **Линт L-C1…L-C6** — механикой существующих помет реестра требований:
   мягкие, жёлтым, с текстами из сида; список запрещённых слов —
   данными (правка с экрана справочников); к помете TBD добавить поле
   «срок устранения» (канон TBR).
3. **Чек обзора** — полкой чек-листов; шаг «Внутренний обзор» задачи 11
   ведёт к нему; пункты — проверяемые вручную, галка с автором
   (это инспекция людей, не вычисление — исключение оговорено).
4. **Глоссарий** — 41 запись сидом в существующий глоссарий с источником
   «NASA SEH App. B» пометкой; коллизии (термин уже есть) — не
   перезаписывать, показать владельцу списком на решение.
5. Адреса по реестру маршрутов (уже ваш файл) — не на слух.

Мера: реестр требований показывает L-C2 на формулировке со словом «при
необходимости» (тест-фикстура); подсказка термина «Валидация» в
глоссарии различает её с верификацией; чек обзора открывается из шага
задачи 11; список слов правится с экрана без пересборки; коллизий
глоссария — отчёт списком, не молчаливая перезапись.
