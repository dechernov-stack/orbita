## Материал канала О2–О4

`prompt-*.txt` — промпты, собранные СЛУЖБОЙ (профиль AP-0201 проекта PJ-0200,
`POST /api/ai/compose`). Они нужны режиму закрытого контура: промпт отдаётся
владельцу, ответ возвращается файлом и вносится через экран «Служба ИИ»
(`POST /api/ai/submit`). При настроенном ключе (`ORBITA_AI_KEY`) тот же
промпт уходит прямым каналом сам.

Ключ задаётся в `.env` стенда (шаблон — `.env.example` в корне репозитория):

```bash
cp .env.example .env      # затем заполнить ORBITA_AI_KEY
docker compose up -d --force-recreate api
```

Проверить, что канал поднялся, можно вызовом службы: при незаполненном ключе
`POST /api/ai/ask` отвечает 503 с причиной и пишет отказ в журнал — это
состояние, а не сбой.
