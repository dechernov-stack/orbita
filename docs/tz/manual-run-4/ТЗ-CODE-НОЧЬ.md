## Правила ночи

1. **Не гадать**: неясность — честный минимум + вопрос владельцу в
   отчёте, не изобретение адресов/проверок/семантики (сторожа адресов
   и связей — в силе).
2. Витрин нет: fixture помечен баннером, прокси подписан, расчёт —
   расчётом.
3. Библиотеки берём версией; форк и патчи ядра — запрещены; GPL/EPL —
   не тянуть.
4. Миграции — с `-- legacy:`; данные стенда не теряются; резервная
   копия до шипа 1.
5. Статусы вычисляются; автор — человек; служебные ключи в печать не
   попадают.
6. Тег на шип; отчёт утром — таблицей «шип · сделано/нет · тег ·
   вопросы владельцу», без пересказа процесса.
