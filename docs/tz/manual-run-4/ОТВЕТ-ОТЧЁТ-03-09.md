# По отчёту 03.09: эквивалентность ReqIF, выкат орка, после выката

Сверено по `origin/main`: теги 32–35, V041, схемы `function` /
`model-element` / `arch-link`, `check_sdoc_roundtrip.py`, ADR-044…049,
разовый скрипт слияния — на месте. Принято.

## 1. Эквивалентность ReqIF — условие сноса своего контура

`check_sdoc_roundtrip.py` проверяет StrictDoc-канал сам по себе; условие
п. 8 было другим — **новый канал не хуже старого на тех же данных**.
Снос — после того, как на демо-проекте (локально) и на стенде (после
выката) одновременно верно:

1. **Старый чек на новом файле**: `check_reqif_roundtrip.py` принимает
   ReqIF, выпущенный StrictDoc, и восстанавливает те же объекты.
2. **Множества совпадают**: SPEC-OBJECTS и SPEC-RELATIONS — одинаковые
   счётчики; множество UID — идентично; связи — те же пары с теми же
   ролями.
3. **Атрибуты поле в поле**: формулировка, статус, метод верификации,
   показатель (op · value · unit), обоснование, источник — равны по
   значению (форматирование не в счёт).
4. **Детерминизм**: повторный экспорт неизменённого проекта — тот же
   файл (кроме CREATION-TIME).
5. **Обратный путь**: импорт StrictDoc-ReqIF в чистый проект даёт
   кандидатов, чей акцепт восстанавливает исходный реестр
   (`foreign_attributes` пусты — свой файл чужих полей не несёт).

Отчёт — таблицей «проверка · старый · новый · совпало». Пять «да» —
снос `ReqifExport.kt`/`ReqifMapping.kt`/`ops/exchange`, сторож
«REQ-IF в нашем коде — 0» включён, ADR-023 закрыт ссылкой на ADR-049.

## 2. Выкат оркестратора — чужие правки не катим

Code остановился правильно: чужие незакоммиченные правки в рабочем
дереве не уходят на сервер вместе с фиксом. Механический путь без
решения об их судьбе сейчас:

```
git stash push -m "чужое: caddy orc.vitalisrun.com, compose ir-storyboard"   # убрать
<выкат фикса PATCH 66d75e6>
git stash pop                                                                # вернуть как было
```

Судьба самих правок (дверь в Caddyfile, монтирование staging) — решение
владельца отдельно, в своём репозитории и своим коммитом; в чужой выкат
они не попадают ни при каком ответе.

## 3. Стенд: после оживления прокси

Прокси Docker Desktop (`http.docker.internal:3128`) — машина владельца;
цикл выката из чистого worktree докатит `mvp-p5-35` сам. После:

1. `ORBITA_TOKEN=<сессия> python3 tools/seed_registries.py` — перезалить
   полку (функции, единицы °/с · В · А, анкеты с напряжением и Δv).
2. Проверить глазами пять экранов и прислать снимки: **Дерево состава**
   (КА поддеревом, дети слиты), **Функции** и матрица «функции × узлы»,
   **Внешняя модель** (fixture с баннером), **граф** от нужды до
   события, **экспорт `.sdoc`** и его ReqIF.
3. Затем — п. 1 на данных стенда.
