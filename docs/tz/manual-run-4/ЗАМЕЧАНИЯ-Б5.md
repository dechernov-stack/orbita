# Замечания ПМИ-4, шаг Б5 (снимок 04.09 13:35)

## Б5-01 · Файл под чужой карточкой — до выяснения шаг не пройден

Строка «Служебная_записка_Минтранс_IoT» ссылается на
`Анализ_идей_IoT_студенты.docx`; тот же файл — под третьей строкой.
Разобрать: `file_ref` записи SD в базе против имени и хеша файла; если
запись верна — рендер берёт ссылку не из своей записи (индекс/ключ
списка). Мера: у каждой строки ссылка ведёт на файл с её же хешем;
тест — три документа, три разных хеша, три ссылки без пересечений.
Если запись неверна — канон Д1 этой записи пересобрать; журнал Б5/Б6
пометить.

## Б5-02 · `undefined` в продукте

«Источник: undefined» — пустое поле показывается `Muted` с причиной
(«— не задан»). Класс: линт клиента на строки `undefined` / `null` /
`NaN` в отрендеренном DOM (сторож рядом с подсказками); поиском по
стенду — ноль вхождений.

## Б5-03 · Старые кнопки извлечений

«Разобрать: профили стейкхолдеров» и «Разобрать: типовые риски» —
виды извлечения по типу, заменённые единым разбором (Д2); ведут в
отказ «нет профиля службы», запрещённый самообеспечением профиля.
Убрать обе. На карточке одно действие — «Разобрать документ»
(«Найдено в документе»); для типа **справка** оно не предлагается
(бриф типа: «участвует в промпте, извлечений не порождает»). Сторож:
кнопок с видами `mission_to_*` на карточке документа — 0.

## Б5-04 · Статус в правой колонке переносится

«карточка заполнена ✓» в три строки — колонке статуса минимальная
ширина, статус чипом; обрезков и переносов статуса — 0 (клятва Т-1).

## Попутно

Б5 ПМИ-4 предполагает **записку по шаблону (md)** — пакеты Р01/Р05
собраны по ней и её якорям; старые docx — законные материалы, но
замысел и урожай на Б6/Г2 берутся по md-записке.

## Ж-01 · Обрыв потока провайдера («Overloaded»)

Живой вызов упал с «поток провайдера не разбирается: провайдер прервал
поток: Overloaded» — перегрузка на стороне модели (529). Наша сторона:
1. **Автоповтор** на 529/обрыве потока — до трёх раз с задержкой 2·4·8 с,
   запрос идемпотентен (частичных записей в модель нет — уже закон);
   счётчик токенов учитывает оборванные попытки честно.
2. **Сообщение человеку — одно и с кнопкой**: «Модель перегружена,
   повторили трижды — не ответила. [Повторить] · [Вставить пакет]»;
   технические фразы — в подсказку, не в основной текст.
3. **Журнал службы**: запись «прерван провайдером: overloaded, попыток 3,
   токенов N» — чтобы счёт живых вызовов и их исходов был виден на
   итоге (О3).
Мера: подложенный 529 в тесте — три попытки, затем сообщение с двумя
кнопками; в журнале — одна запись с причиной; в модели — ничего.
