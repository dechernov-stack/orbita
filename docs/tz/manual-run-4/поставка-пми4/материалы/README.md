# Материалы владельца (в репозиторий не кладутся)

Здесь лежат исходные документы, с которых собирается проект-пример
(`tools/build_example_project.py`, шаг «материалы»):

| Файл | Что это | Вид карточки |
|---|---|---|
| `Служебная_записка_Минтранс_IoT.docx` | записка миссии — постановочный документ | `mission_note` |
| `Анализ_идей_IoT_студенты.docx` | проработка идей применения | `reference` |
| `ТЗ_МКУСС_ПД.docx` | техническое задание смежной разработки | `reference` |

**Сами файлы в git не попадают** (`.gitignore`): репозиторий публичный, а
это документы владельца. Каталог с файлами — на рабочей машине и на стенде
в томе `/files`.

Нет файлов — сборщик честно пропускает шаг и пишет в журнал, чего не
хватило; выдумывать содержимое он не станет.
