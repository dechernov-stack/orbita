# Шаблон: типовой PBS космической системы (полка «Каркас PBS», ред. 2)

**Загружаемый состав — `ПОЛКА-PBS.json`** (135 узлов до 6-го уровня,
130 параметров с единицами и точками зрелости, 10 интерфейсов с
привязкой моделей М2/М3). Этот файл — обзор для чтения; истина — JSON.

Разворачивается в дерево носителей проекта при взятии (одно дерево =
PBS = состав). Уровни: L0 система → L1 сегмент → L2 элемент → L3
подсистема (для КА — L4 агрегаты, где это определяет анкету). Коды —
стабильные, вхождения ×N — свойство вхождения, не узла. Внешние
элементы (РН) — узлы с признаком «внешний».

## L0 · Система (миссия) — корень; проектные требования распределяются сюда

### L1.1 · Космический сегмент
- **L2 · Космический аппарат (КА)** — вхождение ×N по подгруппам построения
  - L3 · **Платформа**
    - L4 конструкция и механизмы (корпус, раскрытия)
    - L4 СЭП — система электропитания (СБ, АКБ, регулятор) · анкета: мощность, энергия, напряжение
    - L4 СТР — терморегулирование (пассив/актив) · диапазоны температур
    - L4 СОС — ориентация и стабилизация (датчики, ДМ, МУС) · точность, скорость разворота
    - L4 БКУ — бортовой комплекс управления (БЦВМ, ПО, хранение)
    - L4 ДУ/КДУ — двигательная установка · Δv-бюджет
    - L4 КТРЛ — командно-телеметрическая радиолиния (C/S)
    - L4 БКС — бортовая кабельная сеть
  - L3 · **Полезная нагрузка**
    - L4 БРТК абонентского диапазона (S / P / …) · чувствительность, каналы
    - L4 АФУ — антенно-фидерное устройство
    - L4 МБРК — межспутниковая радиолиния (ISL), если применимо
    - L4 модуль PNT (если применимо)
  - L3 · Интерфейс с РН (адаптер, разделение) — внешний
- **L2 · Экспериментальная ОГ** (если предусмотрена) — вхождения КА-Э

### L1.2 · Наземный комплекс управления (НКУ)
- L2 · **ЦУП** — центр управления полётом
  - L3 баллистический центр · L3 планирование сеансов · L3 обработка ТМ · L3 командование
- L2 · **Станции управления (НСКУ)** ×N
  - L3 антенная система · L3 приёмо-передающий тракт · L3 модем/оборудование сеанса · L3 серверы станции
- L2 · Средства связи и передачи данных НКУ

### L1.3 · Наземный связной / прикладной сегмент (НСК) — для связных миссий
- L2 · **Региональные станции сопряжения (РСС)** ×N — L3 антенна · тракт · шлюз
- L2 · **Центр обработки данных (ЦОД)** — L3 хранение · обработка · доставка потребителям
- L2 · **Центр управления сетью (ЦУС)** — L3 абонентское управление · тарификация · мониторинг
- L2 · Сеть передачи данных (ССПД)

### L1.4 · Пользовательский сегмент
- L2 · **Абонентские терминалы** по классам потребителей — L3 универсальный · стационарный · мобильный · датчиковый (батарейный)
  - L4 модем · антенна · питание · интерфейс датчиков
- L2 · Прикладные сервисы потребителей (API, кабинеты)

### L1.5 · Сегмент выведения — внешний
- L2 · Ракета-носитель (тип по ограничению) · L2 космодром · L2 адаптер/попутная схема

### L1.6 · Обеспечение и эксплуатация
- L2 · Наземная экспериментальная база (испытания, ЭТБ) · L2 ИТ-инфраструктура и ИБ · L2 эксплуатационная документация и обучение

## Правила шаблона

1. Взятие создаёт узлы L0–L3 обязательно, L4 — по классу миссии
   (для НОО-IoT — платформа и ПН целиком).
2. Каждому узлу L3/L4 сопоставлена анкета (Ф-06): её поля — параметры
   узла; зрелость полей — к точкам.
3. Узел «КА» — единственный носитель для вхождений в построении;
   подгруппа = вхождение КА ×N.
4. WBS-привязка: каждому L2/L3 — пакет работ (шаблон WBS даёт пару).
5. Внешние узлы (РН, космодром) — требования к интерфейсу, не к составу.
