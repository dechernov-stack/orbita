# Ответы на вопросы ночи 02→03.09 (сверено по `mvp-p5-31`)

Сверка: теги 29/30/31, миграции V038–V040, сторожа `validate_one_tree`,
`validate_graph_library` — на месте; `spacecraft_ref` в живом коде — 0.
Ночь принята. Решения по вопросам:

| № | Вопрос | Решение |
|---|---|---|
| 1 | CM-0002: ручные дети без параметров рядом с узлами из модели — сливать? | **Слить**: канон — узел с параметрами (CM-0011, CM-0017); ручной дубль отменяется с историей, его связи и распределённые требования переносятся, след «слито в CM-…». Разовым скриптом на стенде; общее действие «объединить узлы» — не сейчас. |
| 2 | `slew_rate` (нет °/с) и `delta_v_budget` (форма не описана) не перенесены | **Перенести обе.** Справочник: угловая скорость — канон рад/с, ввод и показ °/с (правило углов). Δv-бюджет — **таблица манёвров** на узле КА: `{name, delta_v{value, unit:"м/с"}, note}`, свёртка — сумма в м/с; в анкете платформы — [Т]-поле. |
| 3 | Анкета держит АКБ в А·ч, расчёт ждёт Вт·ч — менять ключ? | **Не менять молча — это разные величины.** Анкета несёт заряд (А·ч) **и напряжение АКБ (В — добавить в справочник)**; `battery_energy` (Вт·ч) — вычисляется с происхождением «А·ч × В»; напряжения нет — разрыв «нет напряжения для энергии». Расчёт читает энергию. |
| 4 | `title` необязателен — разрыв к базированию? | **Да**: мягкая помета всегда, **разрыв к базированию** (как критерий приёмки). Автозаголовок из формулировки не выдумывать. |
| 5 | Дерево «по документам» видит только `source`; урожай Д2 считать источником автоматически? | **Да**: при акцепте кандидата `source{doc, anchor}` заполняется из `provenance.import.item_ref`; ретро — миграцией там, где якорь есть. `source` остаётся правимым. |
| 6 | 212 требований без критерия приёмки, 2 связи без обоснования — стоят пометами | **Правильно.** Пометы — не блок; к базированию — разрыв. 212 — в основном типовые с полки: критерии приёмки для типовых — **моя контент-поставка** на полку (долг записан). RQ-1403/RQ-2104 — обоснования руками (ведущий СИ). |
| 7 | Схему потока переносить на xyflow (тянет переписывание сторожа)? | **Нет, оставить.** Правило «один движок» — экономия, не догма; схема работает под своим сторожем. Переносить, когда схема потребует правок. Долг с условием. |
| 8 | Свой ReqIF (`ReqifExport.kt`, `ops/exchange`, roundtrip-чек) — сносить при StrictDoc? | **Да, но не раньше эквивалентности**: StrictDoc-канал обязан пройти существующий `check_reqif_roundtrip.py` на тех же данных; после — свой конвертер сносится (сторож «REQ-IF в нашем коде — 0» включается тогда). До того — работает, помечен deprecated в ADR. Мой аудит его не заметил — грепал `package.json`, не Kotlin; учту. |

## Инцидент паспорта — это дефект API, не только урок

`PATCH …/state` заменил роадмап целиком. По HTTP-конвенции PATCH —
частичное обновление; полная замена под PATCH — ошибка семантики.
Починить: PATCH сливает, PUT заменяет; тест «PATCH одного поля не
трогает остальные». Восстановление из бэкапа — правильно; повторяться
не должно.

## Справочник единиц — пополнение (данными, с экрана или сидом)

- угловая скорость: канон **рад/с**, ввод/показ **°/с**;
- напряжение: канон **В** (ввод мВ, кВ);
- (проверить наличие) ток — **А**; ёмкость батареи — А·ч есть.
