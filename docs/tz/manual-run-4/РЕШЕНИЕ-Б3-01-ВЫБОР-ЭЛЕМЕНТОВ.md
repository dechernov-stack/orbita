# Решение Б3-01 · Взятие любой полки — выбор конкретных элементов

Первая редакция (флаги `optional_on`) отозвана — владелец прав: это
прятало ошибку в данные. Правильно так: **данные полки полны, а выбор —
у инженера при взятии.** Это правило для всех загружаемых элементов:
каркас PBS, стыки, архитектура, WBS, модели, типовые требования,
комплекты документов.

## 1. Окно взятия — выбор элементов

- дерево/список полки с чекбоксами, счётчиками и поиском; по умолчанию
  отмечен **рекомендованный набор класса** (`default_take` — данными
  полки: для НОО-IoT ISL, PNT, P-диапазон, симулятор, Э-ОГ — не
  отмечены, но видны и берутся одним кликом);
- у каждого элемента — «зачем» и «что от него зависит»;
- итог перед подтверждением: «взять N узлов · M стыков; K элементов
  других полок станут доступны».

## 2. Зависимости — вычисляются по ссылкам, не хранятся

- отметил стык `IF-ISL` → окно подсвечивает требуемые узлы `PL-ISL`
  и предлагает взять их тем же подтверждением (из каркаса, даже если
  каркас уже взят — кросс-полочный выбор);
- снял узел → видно, что от него зависит в этой и в других полках;
- при взятии зависимой полки записи с невзятыми узлами/стыками не
  пропускаются молча и не блокируют: они **серые, с кнопкой «взять
  узел PL-ISL из каркаса»**; можно взять сразу или оставить
  невыбранными — и полка берётся выбранным набором.

## 3. Отказ — только для настоящей ошибки

Ссылка на код, которого нет ни в проекте, ни в доступных полках, —
отказ до записи с именем (как сейчас). Ссылка на невзятый элемент
другой полки — не ошибка, а предложение выбора (п. 2).

## 4. Добор — то же окно

Открыть взятую полку снова: взятое отмечено (снятие — отмена с
историей), невзятое — выбрать; решение об ISL на ЭТП = открыть каркас,
отметить `PL-ISL`, окно само предложит стык, функцию, обмен, цепочку и
пакет WBS. Идемпотентно.

## 5. Данные (поставка обновлена)

`optional`/`optional_on` удалены из всех четырёх полок; вместо них —
`default_take: false` у элементов вне рекомендованного набора класса.
`USR-APP` — в рекомендованном наборе.

## Мера

Новый проект: взять каркас рекомендованным набором; взять стыки —
`IF-ISL` серый с кнопкой «взять узел PL-ISL» → нажать → стык и узел
взяты вместе; архитектура — записи ISL серые, взять их одним
подтверждением с узлом; WBS — то же; повторное открытие любой полки
показывает взятое отмеченным и не создаёт дублей. Ни одного отказа
«возьмите раньше полку» при живых зависимостях.
