Дата: 2026-08-22. Стенд: `docker compose down -v && docker compose up`
(пустая система, ADR-028). Всё — **целиком через интерфейс**, без консоли
и правки базы; автор — из поля «Инженер».

## Замечания по ходу

1. Оба негатива (валидация в никуда, решение без обоснования) показаны
   инженеру прямо на форме с причиной и кодом правила — введённое при этом
   не теряется, исправляется одно поле.
2. Мастер слева на свежезагруженной странице показывает состояние на момент
   загрузки и не обновляется после правок на других вкладках до перехода —
   косметика, не блокер; кандидат в мелкие правки следующего захода.
3. Плановая дата точки (`due`) показана подсказкой на кнопке гейта; вынести
   её в явный текст — тоже кандидат следующего захода.
