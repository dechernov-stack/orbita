## Дефекты, найденные приёмкой (все исправлены по ходу)

Именно на пути «пустая база → интерфейс» всплыло то, чего тесты не видели:

1. **Интерфейс нельзя было завести вовсе**: правило «ровно две стороны»
   (CR-003) жило без схемы, тип ссылался на схему компонента, и форма поля
   `owners` не имела. Появилась 23-я нормативная схема `core/interface`.
2. **Обязательный маяк (Р5) нельзя было включить**: у `enabled: const true`
   нет `type`, форма рисовала текстовый ввод и слала строку. Форма научилась
   const-полям: значение принадлежит схеме, не инженеру.
3. **Сценарий нельзя было создать**: редактор навешивал `lifecycle` всем
   видам, а схема сценария его не допускает. Служебные поля правки теперь
   ставятся только тем, чья схема их несёт.
4. **Версии входов сценария** форма выразить не могла — и не должна: версию
   знает хранилище. При записи сценария отсутствующие версии фиксирует
   сервер; явно заданные не перетираются.

Плюс подтверждена работа ADR-027 на живом пути: связь, добавленная правкой,
появилась в дереве, а класс потребителя, забытый в traces_up, был отклонён
формой с причиной (Р9) — и дозаполнен без потери введённого.
