# Проект-пример «НОО-IoT · золотой путь» — артефакты обзора

Всё здесь собирается одной командой на живом стенде:

```bash
python3 tools/build_example_project.py --rebuild
```

| Файл | Что это | В git |
|---|---|---|
| `ЖУРНАЛ-СБОРКИ.md` | что и кем создано, какие разрывы остались — числа сняты прогоном | да |
| `ГДЕ-ЧТО-ХРАНИТСЯ.md` | сущность → таблица/файл → экран → печать | да |
| `печать/*.pdf`, `печать/*.docx` | выпуски ConOps, SEMP, ICD, MCReport с сервера | нет |
| `требования.sdoc`, `требования.reqif` | обмен со StrictDoc и ReqIF | нет |
| `выгрузка-знаний.zip` | выгрузка знаний проекта с отпечатком | нет |
| `снимки/*.png` | снимки экранов под учёткой РП | нет |

Файлы с содержанием примера в публичный репозиторий не кладутся
(`.gitignore`): они воспроизводятся скриптом за один прогон.

`--rebuild` снимает прежний пример **отменой**: истории система не стирает,
и в базе остаётся отменённый проект. Удалить его совсем каналом нельзя —
удаления проекта в системе нет; чистка делается транзакцией в БД по просьбе
владельца и только после `pg_dump`.

Расчёты моделей живут отдельно — `tools/example_models.py`, их сторож —
`tools/validate_example_models.py` (в `ci/checks.sh`).
