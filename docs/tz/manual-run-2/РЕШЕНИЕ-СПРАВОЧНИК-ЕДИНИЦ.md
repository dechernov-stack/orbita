# Решение (ранга ADR): справочник единиц — один на систему

## Принцип

Каждое число в системе несёт единицу, и единица обязана существовать в
**справочнике единиц** — объекте данных, не константах кода. Хранение —
только в канонической единице своей размерности; всё остальное — на
границах.

## Устройство справочника (данными, библиотечная область)

Запись: **размерность** (масса, время, деньги, угол, доза, энергия,
скорость передачи…) · **каноническая единица хранения** · допустимые
единицы ввода с коэффициентами · предпочтительная единица показа (если
отлична от канона).

Стартовый канон (решения владельца):
- масса — **кг**; время — **с**; угол — **рад** (градусы — единица
  границ, §7 задачи построения — частный случай этого правила);
- деньги — **млн ₽**; иные валюты — единицы ввода, конверсия фиксирует
  **курс и дату** в происхождении числа;
- доза — **Зв** (заводится сейчас же — метрика Г12 её уже требует);
- составные (бит/с, Вт·ч, циклы АКБ) — самостоятельные записи со своей
  размерностью, не «вычисляются» из базовых.

Имена единиц уникальны и недвусмысленны (доза — только Зв/Гр, чтобы не
столкнуться с углом).

## Правила

1. **Хранение — канон.** Строка единицы в любом значении обязана
   принадлежать справочнику — ограничение, сторож в CI: «все unit-строки
   системы ∈ справочнику».
2. **Границы переводят.** Ввод, импорт, пакеты ИИ (канал вставки Б-01 —
   тоже граница): несистемная единица → конверсия с записью происхождения
   («переведено из 30 min»); **неизвестная единица → отказ с предложением
   открыть справочник и добавить** — не тихая строка мимо словаря.
3. **Новая единица — правка справочника**, не кода. Зиверт понадобился —
   добавили запись, система её знает везде.
4. **Показ из справочника.** Словарь отображения UI генерируется из
   справочника — один источник; копия-мапа в клиенте умирает.
5. Отображение может отличаться от хранения (показ в минутах при
   хранении в секундах) — но только единицей показа из справочника.

## Задача Code — минимум в спринт, остальное волной

Спринт: завести справочник данными (текущие единицы системы + Зв, млн ₽);
сторож принадлежности в CI; конверсия на границе пакетов и импорта с
отказом на неизвестном. Волной после: показ из справочника (замена
клиентской мапы), типизация углов §7, деньги О-20 стартуют сразу в каноне.

Мера: пакет с «30 min» ложится как 1800 с с происхождением; пакет с
«фунтами» — отказ с именем единицы; сторож валит сборку на unit-строке
мимо справочника (тест с нарочной строкой).
