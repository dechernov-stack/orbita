# Т-1: решения по отчёту вёрстки + доработка помет

## 1. Семантика помет — доработка (сигнал 140/212 мёртв)

`current.version != firstApproved.version` — арифметика версий, не
содержательность: технические волны (канонизация единиц, перелинковка,
миграции областей) зажгли пометы на двух третях реестра. Правится в
`rowMarks`:

1. **«Изменено после утверждения»**: сравнение содержательных полей —
   формулировка, показатель, распределение, уровень, категория — против
   якоря. **Якорь передвигают служебные правки**: якорь = первая
   утверждённая версия либо последняя после неё версия, изменённая
   служебной учёткой (`ci-runner`, миграции). Инженерская правка горит,
   техническая волна — нет. «30 мин → 1800 с» — не изменение.
2. **«Пересчитан после базирования»**: только от механизма пересчёта —
   `mop.provenance.source = "recomputed"` с датой позже базирования.
   Механизма пересчёта пока нет → флаг честно ноль. Молчащий флаг лучше
   врущего.

Мера доработки: на живом реестре пометы возвращаются в разряд исключений;
счётчики в строке разрывов сходятся с ручной проверкой трёх любых
помеченных (в отчёте — какие три проверены и чем изменение содержательное).

## 2. Ответы на три вопроса отчёта

1. **Плотность — принять 27.** Мера «≥30» писалась до трёхстрочного
   тулбара; строку мельче 26 px не жать — читаемость дороже круглого
   числа. Тулбары ужать на 2 px каждый, если без тесноты. Мера в задаче
   Т-1 заменяется: **≥27 строк на 1440×900, ≥33 на 1920×1080, обрезок 0.**
2. **Порядок конфигуратора**: порядок таблицы — закон, сделано верно.
   Дефект эталона признан (круг 4 проверял состав, не порядок), эталон
   исправлен, в генератор вшита проба порядка — обновлённый
   `reference-req-registry.html` идёт этой же поставкой в `reference2/`.
3. **«Декомпозировать» — автоподстановка нужна**: создание открывается с
   родителем = текущее требование, связь трассировки вверх ставится
   автоматически, уровень наследуется; носитель — пустым (ребёнок может
   уйти на другой элемент). Отмена создания не оставляет следов.
