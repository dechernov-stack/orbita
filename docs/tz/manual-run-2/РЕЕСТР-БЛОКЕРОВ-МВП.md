# Реестр блокеров MVP-прохода

(вход владельца, 2026-08-27, дословно)

Формат: № · шаг ПМИ · что не так · что нужно · статус. Чинится вне очереди,
выкат накатом, ответ владельцу «починено, продолжайте с шага N».

## Б-01 · А7/Б2/Б3/Д3 · пакет не внести

На экране «Предложения ИИ» нет входа для заготовленного пакета: ни файла,
ни поля вставки, доступного без живого прогона.

**Нужно:** действие **«Вставить пакет»** на экране предложений — принимает
JSON пакета (вид — из самого пакета), разворачивает предложениями на
акцепт, источник в журнале «пакет», модель не вызывается. Работает для
всех видов шагов ПМИ-2 (порождающие и правящие).

Статус: **открыт, проход стоит на А7.**

## Б-02 · откат шага · постановку нельзя отменить

Цели/нужды/сервисы, попавшие в модель ошибочно, из интерфейса не удалить
и не отменить — ошибочный шаг не откатывается штатно.

**Нужно:** действие **«Отменить»** на объекте постановки — мягкая отмена
с историей (механика та же, что у отменённого сервиса: объект остаётся,
трассировки на него честно показывают разрыв); массово — по выбранному с
подтверждением числом. Жёсткого удаления не вводить — история
неприкосновенна.

**Плюс разово:** вычистить отменой мусор текущей попытки на стенде
владельца — список объектов он даст (или сам после появления кнопки).

Статус: **открыт.**
