# Круг 3 стартового потока: «Взять» с видимым результатом; контролы

Два замечания владельца с живого прохода, оба по переделанному потоку.
Эталон `reference-project-start.html` обновлён этой же поставкой (Ш2).

## 1. «Взять из библиотеки» — действие обязано показывать результат

Сейчас нажатие ничего не порождает на глазах — витрина, притворяющаяся
формой. Модель по эталону:

1. **«Взять» — немедленное действие.** Нажатие импортирует пачку фрагмента
   в проект (механизм готов) и **на месте** меняет строку: «Взято ✓ ·
   создано N · состав · отменить». Пока идёт — кнопка занята, повторное
   нажатие второго набора не создаёт (идемпотентность по связи «применяет»).
2. **Счётчик шага живой**: полоса «Создано этим шагом: 34 требования ·
   13 шаблонов…» обновляется каждым взятием.
3. **«Отменить»** — до конца пути: удаляет созданное именно этим взятием
   (по связям «применяет» и журналу применения); если созданное уже
   тронуто руками — отказ с перечнем тронутого, не молчаливое удаление.
4. Итог пути (Ш3 и свёрнутая строка) перечисляет созданное числами.

## 2. Нативные контролы браузера — вон; это правило дизайн-системы

«Выберите файл» и системный выпадающий список — заменить:

1. **Загрузка**: drop-зона + стилизованная кнопка «Выбрать файлы»
   (нативный input скрыт); список выбранного — строками с карточками.
2. **Тип документа — чипами**, не списком: пять значений видны сразу,
   выбор одним нажатием (по эталону карточки документа).
3. Правило общесистемное: **нативные select / file input / date input в
   продуктовых экранах запрещены** — только компоненты оболочки. Где
   компонента нет — вопрос владельцу, не системный контрол.

## 3. Radio вместо чекбокса — служба разбирает один файл из многих

Найдено владельцем: в списке материалов стоит radio, и на Ш3 служба берёт
**один** документ вместо всех отмеченных.

1. **Чекбоксы, не radio**: участие документа в промпте — множественное;
   по умолчанию отмечены все с заполненной карточкой, снятие — осознанное
   исключение. Правило общесистемное: radio допустим только там, где выбор
   взаимоисключающий по смыслу; множественность — всегда чекбокс.
2. **`compose` берёт все отмеченные**: блок материалов в промпте
   перечисляет документы **поимённо** («Документы в промпте — 2 из 3,
   справка исключена вами») — по обновлённому эталону Ш3; журнал вызова
   хранит перечень вошедших документов.
3. Приёмка: два документа отмечены → оба видны в предпросмотре и в журнале
   вызова; снятый отсутствует; radio в новых экранах поиском не находится
   (кроме взаимоисключающих выборов, каждый — с обоснованием в отчёте).

## Приёмка круга

- [ ] взятие набора меняет строку на месте; счётчик шага растёт; снимок
      до/после рядом с эталоном;
- [ ] повторное нажатие не плодит дубли (проверка по связям «применяет»);
- [ ] «отменить» убирает созданное этим взятием; тронутое руками — отказ
      с перечнем;
- [ ] тип документа — чипами; загрузка — без нативного вида; по стенду
      поиском не находится ни одного системного select/file input в новых
      экранах;
- [ ] итог в Ш3 и в свёрнутой строке пути — числами, сходится с журналом.
