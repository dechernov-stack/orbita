# Отчёт О-4 · «Профили службы»

Эталон: `docs/ui/reference2/reference-ai-profiles.html` (круг 1, собран
Claude по пакету — владелец даёт снимки и правки кругов).
Версия стенда: тег `stand-queue-01`.

## Сделано

- Сервер: композер промпта разобран на блоки с атрибуцией источников
  (profile / model / input) — `composeBlocks`; `compose` — склейка тех же
  блоков (второй сборки текста нет); `/ai/compose` отдаёт `blocks`.
- Экран `AiProfiles.tsx` вместо реестра-заглушки: список профилей с видами
  пакетов, вкладки «Определение» (полная форма с лестницей статусов) и
  «Промпт» — предпросмотр с легендой и цветными блоками по источнику.

## Мера позиции

Запрет из профиля виден строкой в предпросмотре промпта — снимок в сессии:
блок «Ограничения проекта · из профиля» перечисляет Р1/Р2/Р3/Р4/Р7
построчно (стенд, AP-0001 проекта PJ-0001).

## Расхождения с эталоном / вопросы владельцу

1. Вкладки «История» в реальном экране нет (история — внутри формы
   определения, вкладка ObjectEditor) — оставить так или вынести?
2. mark-подсветка первого запрета в эталоне — художественный акцент
   стенда, в живом предпросмотре все запреты равноправны.
3. Состояние 3 (пустой реестр) — текст приглашения в мастер-путь: принять
   или поправить кругом.
