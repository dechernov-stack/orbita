# Справочник единиц «Орбиты» — стартовое наполнение

Полка справочников (область LIB), сосед глоссария; **применяется каждому
проекту автоматически при создании** — tailoring не требуется, единицы не
отклоняют. Правки — только правкой справочника.

Форма записи: размерность · **канон хранения** · единицы ввода
(коэффициент к канону) · показ по умолчанию. Особые типы конверсии
помечены: «сдвиг» (°C), «лог» (дБ-величины — линейной конверсии нет,
сравнение напрямую), «курс» (валюты — конверсия фиксирует курс и дату).

## Базовые

| Размерность | Канон | Ввод (коэф.) | Показ |
|---|---|---|---|
| Масса | **кг** | г (0,001) · т (1000) | кг |
| Длина | **м** | мм (0,001) · км (1000) | км для орбит, м прочее |
| Время | **с** | мин (60) · ч (3600) · сут (86 400) · год (31 557 600) | по полю: с/мин/сут |
| Угол | **рад** | ° (π/180) · угл. мин (π/10 800) | **°** (рад — только внутри расчётов, §7) |
| Скорость (и Δv) | **м/с** | км/с (1000) · км/ч (0,2778) | м/с |
| Температура | **К** | °C (сдвиг +273,15) | °C |
| Давление | **Па** | бар (10⁵) | Па / бар по полю |
| Частота | **Гц** | кГц (10³) · МГц (10⁶) · ГГц (10⁹) | МГц/ГГц по полю |

## Правила пополнения

1. Новая размерность/единица — запись сюда, не код; составные (Вт/кг,
   бит/с на терминал) — самостоятельными записями по мере нужды.
2. Имя единицы недвусмысленно во всём справочнике («рад-доза» ≠ «рад»
   угловой — угловой в справочнике отсутствует, храним в радианах без
   пользовательского ввода в них).
3. Импорт/пакет с единицей вне справочника — отказ с предложением
   добавить; тихих строк мимо словаря нет.
