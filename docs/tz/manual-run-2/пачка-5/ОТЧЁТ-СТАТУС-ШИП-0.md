## Дополнение: шип 5 — обе позиции «под вопросом» закрыты

**Вставка таблицы сравнения в раздел AoA (Д2).** Механизм был в коде
(`Documents.kt`: раздел 2 документа `mission_concept` несёт вставку
`constellation_compare_table` со снимком времени расчёта и ссылкой на
сценарий), но тестом закрыт не был — мог тихо отвалиться. Теперь держит
`MissionConceptTablesTest`: таблица попадает в раздел с обоими вариантами,
временем расчёта и сценарием; **без расчёта таблица не выдумывается**, а
альтернативы в разделе остаются.

**Меры §5 карты после правки углов.** Инварианты углов закрыты
`WalkerAngleInvariantsTest` (разброс RAAN, равноотстояние соседних
плоскостей, ССО-наклонение, узлы трасс). Карта ёмкости перепрогнана на
стенде — сценарий `SC-0001`, горизонт «сутки», построение Walker 40/5 · 550 км:

| мера | значение |
|---|---|
| ячеек карты | 1208 |
| доступность, средняя | 0.862 |
| доступность, худшая | 0.000 (полярные и краевые ячейки) |
| проходо-минуты, медиана | 2272.2 |
| проходо-минуты, диапазон | 0.0 … 5284.5 |
| ячеек «ok» / «gap» | 1127 / 81 |

Карта считается и различает классы ячеек; 81 ячейка с разрывом — это
законный результат для 40 КА на 550 км, а не сбой расчёта. Слипания
плоскостей, искажавшего карту, в текущих числах не видно: распределение
проходо-минут широкое и монотонное по широте.
