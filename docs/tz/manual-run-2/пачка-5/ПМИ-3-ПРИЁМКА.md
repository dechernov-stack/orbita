# ПМИ-3. Приёмка продукта целиком: все экраны, пустой проект → KDP-B

**Токены.** Живых вызовов по умолчанию **ноль**: все ИИ-шаги — вставкой
пакетов. Подготовка Code: **срезать ответы прошлых живых вызовов из
журнала службы в пакеты** (разбор записки, цели·нужды, требования) —
переиспользование бесплатно. Резерв **[Ж-1]** — один живой вызов по
решению владельца в К4; интерактивные генерации — внешним контуром
(Claude-проект, выгрузка Ф-10).

**Условия.** Живой стенд; проход новым проектом; до старта — резервная
копия тегом; версии — тегами в отчётах. Блокер — сообщением; остальное —
строкой в журнал прохода.

Форма: № · действие · где · ожидаемо («вышло» — по ходу).
