# Концепция продукта: «Работа фазы» — после мастера продукт ведёт

## Диагноз

Мастер доводит до постановки и обрывается. Дальше — фаза: месяцы работы
команды по регламенту, и именно у неё нет лица в продукте. Операции —
справочная карта, разрывы — в готовности, задания — механизм без сцены.
Ответа «куда идти» нет.

## Решение: раздел «Работа» — главный экран проекта после мастера

**Список задач фазы = операции регламента, развёрнутые в ведомые
процессы.** Каждая задача — карточка процесса:

- **Зачем** — из регламента человеческим языком (полка, не хардкод);
- **Вход** — что нужно и есть ли, вычислено («ожидает: Требования —
  черновик» / «вход готов»);
- **Шаги с подсказками** — полоса-проводник (паттерн уже живёт на
  документе и постановке): каждый шаг — «что сделать · где · чем
  поможет служба», переход одним кликом к преднастроенному месту;
- **Выход** — артефакт (Д-документ, объекты) со зрелостью к точке;
- **Готовность** — разрывы операции как её чек-лист (те же, что в
  готовности к точке, разрезом операции);
- **Люди** — исполнители; назначение разрыва = задание (механизм есть,
  доделать).

Статусы **вычисляются**: не начата (вход не готов) → доступна → в
работе → выполнена (выход в зрелости). Параллельность — данными фазы.

## Навигация «куда идти» — три разреза одного состояния

**Работа фазы** (командный: задачи-процессы) · **Мои задания** (личный:
адресованные разрывы) · **Готовность к точке** (целевой: что держит
точку). «Следующий шаг» в шапке — верхушка «Работы».

## Судьба накопителя (термин «фикс» закрыт)

Ф-12…Ф-15 вливаются в это решение частями: проводник — механика шагов;
стейкхолдеры и матрица — задача 1; полки и справочники — места работы
задач 5–6 и опора подсказок. Ф-06.3 — внутри задачи 5.

## План исполнения

1. **Я**: бриф + эталон экрана «Работа» (список задач + карточка
   процесса, два состояния) — следующей поставкой; контент карточек
   Pre-A — из регламента на полку.
2. **Code**: фундамент — доделать процесс-задачу (задания, зависимости
   «ожидает», «Мои задания», Tooltip-линт) по давнему заданию; статусы
   операций вычисляемыми; отчёт по её текущему состоянию — первым.
3. Проход ПМИ продолжается по шагам В–Е поверх: «Работа» строится не
   вместо прохода, а как его продуктовое русло.
