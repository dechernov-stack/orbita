# Круг 2 «Работы»: лента читается, окна не вырождаются

## 1. Модель окон: ярусная раскладка внутри интервала (дефект модели — мой)

Вырождение: задачи одной точки имеют старт = конец (дедлайн входа =
дедлайн выхода = SRR) → полосы-чёрточки. Правка модели, по-прежнему без
ручных длительностей:

- **Топологический ярус** цепочки зависимостей внутри межвехового
  интервала делит интервал на равные доли: ярус 1 (входы готовы/`always`)
  — первая доля, ярус 2 — вторая, … Окно задачи = её доля(и) яруса до
  своей точки. Итеративно-параллельные одного яруса — параллельные
  полосы одной доли.
- Это **расчётная сетка, не обещание** — подпись у ленты: «окна —
  расчётные доли интервала до точки по порядку зависимостей».
- Красное правило прежнее (до точки < порога при незакрытом), «сегодня»
  и вехи ◆ — обязательны на шкале.

## 2. Вёрстка ленты — вернуться к эталону

1. **Шкала дат сверху**: деления, вехи ◆ именами (SRR · SDR/MDR ·
   KDP-B), линия «сегодня». Сейчас шкалы нет вовсе.
2. **Полоса несёт подпись внутри** («в работе · разрывы 5» / «ждёт 4»);
   минимальная ширина полосы — 90 px, не влезает — подпись рядом.
   Обрезок текста 0 (сейчас «шаг 2 из…» обрезан).
3. **Статус — текстом в колонке имени** (вторая строка, как в эталоне
   списка), не пилюлей-боксом моноширинным.
4. **Имя задачи — текст, не синяя ссылка**: вся строка — цель клика
   (правило Т-1); синее — только действия.
5. **Легенда — не абзац над лентой**: короткая строка мелким под лентой
   + тултипы на полосах (механика подсказок обязана здесь работать).
6. **Двойной заголовок убрать** («Работа фазы» дважды); счётчики — в
   одну строку с переключателем Лента|Список.
7. **Панель раздела с единственным пунктом схлопывается** — правило
   общесистемное: раздел «Работа» открывается сразу экраном, пустая
   белая панель не занимает треть окна.
