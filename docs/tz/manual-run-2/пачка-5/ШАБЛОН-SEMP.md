# Шаблон: SEMP (План управления системной инженерией) — полка Б

Структура — Прил. 1 БП-PA (8 разделов). Особенность: SEMP наполовину —
самоописание конфигурации проекта; колонка «Источник в системе» задаёт
автонаполнение вставками, инженер правит и дополняет поверх.

| № | Раздел | Содержание | Источник в системе (вставка) |
|---|---|---|---|
| 1 | Назначение и область | проект, фазы, связь с FA | паспорт: имя, фаза, ссылка FA |
| 2 | Техническое резюме | система, границы, ключевые задачи фазы | замысел (4 поля) + класс миссии + задачи «Работы» текущей фазы |
| 3 | Организация | роли, ответственность, подрядчики | учётки и права (В3); стейкхолдеры-поставщики со связями на узлы |
| 4 | Технические процессы | реализация процессов NPR 7123.1 | **таблица соответствия**: процесс → механизм «Орбиты» → место (требования→реестр с трассировкой; интерфейсы→реестр интерфейсов; риски→реестр; конфигурация→версии и базирование с основанием; верификация→события и матрица) |
| 5 | Технические обзоры | перечень, критерии входа/выхода, RFA/RID | лента вех фазы + группы проверок готовности каждой точки |
| 6 | Отклонения (tailoring) | согласованные отклонения с обоснованием | **записи tailoring со следом** (неприменимо: кто, когда, почему) — уже данные |
| 7 | Инструменты и среда | управление требованиями, MBSE-модель, данные | конфигурация стенда: «Орбита» (реестры, модели, документы), карта, справочники; MBSE-модель — сама система |
| 8 | Согласование | подписи, версия, порядок актуализации | фиксации переходов документа (историей) |

*Правила заполнения: разделы 4–7 приходят вставками из конфигурации —
«текст устарел» работает при изменении источника; раздел 2 и свободные
абзацы — рука инженера; типовое наполнение НОО-класса — образцом на
полке рядом (нитка «образец → шаблон»).*

---

## Мини-задача Code (полкой, без ядра)

1. Вид документа `semp`; шаблон `DT-9002` сидом по таблице выше;
   глоссарий: термин SEMP с брифом.
2. **Вставки конфигурации** для разделов 4–7: соответствие процессов
   (данными полки), обзоры из ленты+готовности, tailoring из записей
   отклонений, инструменты из описания стенда. Механизм вставок В1 —
   существующий; «текст устарел» обязан срабатывать.
3. Вид пакета `semp_draft` (черновик свободных разделов службой) — в
   реестр видов; живого вызова не требует, внешний контур годится.
4. Шаг задачи 1 Phase A «SEMP по шаблону» ведёт в создание документа
   по `DT-9002` преднастроенно.

Мера: создание SEMP из шаблона на живом проекте — разделы 5–6 приходят
наполненными из конфигурации (лента и tailoring-записи видны текстом);
правка даты вехи → «текст устарел» на разделе 5; печать docx держит
таблицу раздела 4.
