1. **Б-03 отменяется.** Профиль «Извлечение из документов» не нужен:
   виды извлечения заменены единым смысловым разбором (решение §смысловой
   разбор). UI-фильтрация несовместимых пар профиль×вид остаётся в силе.
2. **ПМИ-2, шаг Б2** исполняется вставкой `ПАКЕТ-РАЗБОР-ЗАПИСКИ.json`
   (вид `document_semantic_parse`) — пакет `06-стейкхолдеры` умирает,
   готовить его не надо. Урожай на акцепте раскладывается по адресам:
   стейкхолдеры → полка А2, нормативы-кандидаты (все с `need_ref`),
   сервисы/цели/нужды → постановка, география → маски, суммы — каноном.
3. **Приёмка Д1/Д2 — эталонами пачки**: разбор системы на тех же двух
   docx обязан дать канон с потерей текста 0 и карту, эквивалентную
   эталонной (состав классов и счётчики summary; формулировки могут
   отличаться — состав нет). Меры решений (записка: ≥6 стейкхолдеров,
   6 need_ref, 7–9 млрд ₽ каноном; анализ: 36/36 строк, критерии
   классом, derived помечен) — обязательны.
