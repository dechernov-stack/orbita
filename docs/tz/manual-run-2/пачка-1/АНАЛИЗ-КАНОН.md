# Оценка идей использования спутникового IoT — студенческий анализ {#b0}

## Методика оценки {#s1}

<!-- b1 -->
Каждая идея оценена по трём параметрам по шкале 1–10:

1. **Пользователи** — потенциальная база подключений или устройств
2. **Востребованность через спутник** — насколько спутник критичен (не GSM/Wi-Fi)
3. **Экономическая целесообразность** — соотношение выгоды к затратам
