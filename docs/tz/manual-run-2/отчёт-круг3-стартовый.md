# Отчёт: круг 3 стартового потока

Оба замечания и правило контролов исполнены; эталон Ш2/Ш3 заморожен.
Живые проверки — на одноразовом стенде (чистый стенд не тронут);
снимки — `снимки-т1/к3-*.png`.

## 1. «Взять» — действие с видимым результатом

- **Строка меняется на месте**: «Взято ✓ создано N · состав · отменить»;
  пока идёт — «беру…», прочие кнопки взятия заняты.
- **Идемпотентность на сервере** — по связи «применяет»: повторный POST
  возвращает 200 с `existing` (живые экземпляры), второй набор не
  создаётся. Взятие видно и после перезахода: `/library/shelves?project=`
  отдаёт `applied {count, by_type}` из тех же связей — отдельного
  состояния у взятия нет.
- **«Отменить»** — `POST /library/fragments/{id}/revert`: гасит
  (Cancelled) созданное именно этим взятием; **тронутое руками** (история
  длиннее создания) — 409 с перечнем поимённо, не молчаливое удаление.
  После отмены взятие снова доступно. Мера — LibraryChannelTest
  (идемпотентность · отмена · отказ по тронутому); живой прогон:
  15 создано → повтор 0/existing 15 → отмена 15 → правка CM → 409.
- **Счётчик шага живой**: «Создано этим шагом: 12 элементов ·
  3 интерфейса — со связями «применяет»…» — растёт с каждым взятием;
  те же числа — в Ш3 («Наборы: …») и в паспорте пути
  (`start_path.created_counts`) — свёрнутая строка «Начало пройдено»
  в Жизненном цикле дописывает «Создано путём: …» числами.

## 2. Нативные контролы браузера — вон

- Загрузка Ш2: **drop-зона** (перетаскивание работает) + стилизованная
  кнопка «Выбрать файлы» (нативный input скрыт), выбранный файл — строкой
  с «убрать». **Тип документа — чипами**, пять значений видны сразу.
- Общий компонент оболочки `ui/Select.tsx` (кнопка + поповер, Esc/клик
  мимо): заменил нативные select в новых экранах — класс миссии (Ш1),
  группировка реестра Т-1, селектор носителя в карточке 5б, вид пакета
  в профилях службы.
- Поиском по новым экранам системных select / видимых file input нет.
  **Date input** в форме создания проекта остался нативным: компонента
  календаря в оболочке нет — по правилу круга это вопрос владельцу
  (нужен эталон календаря), не самодеятельность.
- Попутно закрыт дефект круга 2: имя карточки с пробелом приезжало как
  «Имя+карточки» — сервер не декодировал «+» в query; разбор переведён
  на rawQuery + URLDecoder (все маршруты). Подписи типов документов
  появились в реестре подписей (`sd_kind`) — чипы и карточки пишут
  «записка миссии», не код.

## 3. Чекбоксы вместо radio — служба берёт все отмеченные

- Участие документа в промпте — **множественное**: чекбоксы; по умолчанию
  отмечены все с заполненной карточкой; подпись над списком — текстом
  эталона. Прежний radio удалён.
- `compose`/`ask` получают ВСЕ отмеченные: блок материалов начинается
  «Документы в промпте — 2 из 3 («…» исключена вами):» и перечисляет
  поимённо; тот же перечень — в Ш3-предпросмотре; журнал вызова хранит
  промпт целиком — перечень в нём. Паспорт пути хранит `source_refs`
  (прежний одиночный `source_ref` читается для совместимости).

- [x] взятие меняет строку на месте; счётчик шага растёт; снимки

- [x] тип — чипами; загрузка без нативного вида; select/file input в
      новых экранах поиском не находятся (date — вопрос владельцу выше);

      (`к3-ш3-материалы-поимённо.png`); свёрнутая строка дописывает
