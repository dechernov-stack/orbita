# Отчёт О-9: Портфель (бриф + эталон круга 1)

Вёрстка по `reference-portfolio.html`; снимок живого стенда —
`снимки-т1/о9-портфель.png`.

## Сервер

`GET /views/portfolio` — входная дверь одним запросом (прежний клиент
собирал портфель N+1 вызовами): имя · фаза · руководитель (роль lead при
учётках, иначе автор создания) · ближайшая точка с русской подписью и
счётчиком незакрытого · действующий возврат из паспорта · путь начала ·
последняя активность (последняя запись истории проекта: автор, время,
основание правки — «что нового» и есть change_ref). Сортировка по
последней активности — сервером. Точка без конфигурации проверок
(PDR в Phase A) — счётчик честно отсутствует, не ноль и не отказ.
Мера — ReqRegistryTest (строка несёт имя, подпись точки, счётчик,
активность, руководителя).

## Клиент (Portfolio.tsx — переверстан целиком)

- **Строки, не плитки**; вся строка — цель клика (открывает проект);
  «Создать проект» — первичная кнопка, «загрузить из файла» — ссылкой
  (ведёт в существующую загрузку).
- В строке: имя + руководитель · чип фазы · «ближайшая ‹подпись›» +
  «не закрыто · N» (ноль — зелёное «готово») · возврат красным маркером
  ВМЕСТО счётчика · чип пути («начало: шаг N из 3 · продолжить» —
  открывает путь; «начало пройдено» — глухой) · последняя активность
  («сегодня/вчера/N дн. назад» + автор + что).
- **Первая установка** — приветствие по эталону (текст дословно),
  «Создать первый проект» + «или загрузить проект из файла»; прежний
  молчаливый редирект в форму умер.
- До 20 проектов — без поиска, фильтров и группировок (бриф §5, §8).

## Круг 2: активность — человеческая; «system» запрещён

- **§1.1 Один список служебности** — `orbita.req.ServiceAuthors`
  (`system`, `ci-runner`, плюс исторические миграции с created_by
  «миграция V0NN: …» — всплыли на живом стенде): им пользуются и якорь
  помет, и активность портфеля. Активность строки — последняя правка
  НЕслужебной учётки; служебная волна поверх человеческой «что нового»
  не перекрывает (тест).
- **§1.2** Проект без единой содержательной правки — тихая строка
  «служебное обновление · ‹когда›» без имени учётки (тест).
- **§1.3** «system» на экраны не выходит: показ автора — карта авторов →
  учётка → имя; неизвестный «system» — «служебная запись». Применено в
  портфеле и истории карточки. Вперёд служебное пишется `ci-runner` —
  дефолты createdBy ядра переведены. Приёмочный обход живого стенда
  (портфель · цикл · реестр · карточка с историей): «system» поиском
  не найден.
- **§2 PDR** — счётчика нет и нет ошибки; в ленте цикла у первой
  непройденной вехи вне горизонта — тихая подпись «проверки появятся
  с регламентом Phase B» (снимок `о9-пдр-подпись.png`).
- Живой верх портфеля: «Чернов · создан SD-0005» и «Чернов · правка
  SC-0002» — инженерная работа, не хроника выкаток
  (`о9-портфель-круг2.png`).
