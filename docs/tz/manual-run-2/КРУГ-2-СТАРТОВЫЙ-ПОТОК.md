# Круг 2 стартового потока: даты вех и исходные документы

Два замечания владельца с живого прохода — оба по переделанному потоку,
чинятся кругом. Эталоны обновлены той же поставкой:
`reference-create-project.html` (пример отказа порядка дат в состоянии 3),
`reference-project-start.html` (карточка исходного документа в Ш2).

## 1. Плановые даты вех — порядок и календарь

1. **Календарь открывается от предыдущей заданной вехи**, не от сегодня:
   ввод даты MCR стартует с даты внутреннего обзора (первая веха — от
   сегодня). Мелочь, экономящая листание на годы вперёд.
2. **Порядок дат — инвариант, проверяет сервер и форма**: дата точки не
   может быть раньше даты предыдущей точки фазы. Нарушение — отказ с
   именами обеих точек («MCR не может быть раньше внутреннего обзора»),
   поле подсвечено — как в эталоне. Частично заданные даты законны
   (КТ-2 задана, КТ-1 нет — не ошибка); «дата не задана» — законно всегда.
3. Проверка — та же на создании проекта, в паспорте и в любом месте правки
   дат вех: **одним правилом на сервере**, не тремя копиями по формам.

## 2. Исходные документы: загрузка, карточка, разбор

Сейчас «Библиотека → Исходные документы» не умеет принять файл, а файл без
описания — склад, не библиотека.

1. **Вид `source_document`** (SD-): форма №3 из библиотечной задачи —
   файл + карточка: наименование, тип (записка миссии / норматив /
   даташит / справка / прочее), источник (организация), дата документа,
   аннотация. Вид один, живёт в **обеих областях**: исходные документы
   проекта — проектная область, полки А3/А4/В2 — библиотечная.
2. **Загрузка**: `POST` файла → карточка формой (тип и наименование
   обязательны, остальное можно позже); файл хранится при стенде, входит
   в резервную копию О-18.
3. **Разбор ИИ — по типу документа, с акцептом**: у карточки действия
   «Аннотация» (любой тип) и типовые извлечения — записка → профили
   стейкхолдеров и типовые риски (виды извлечения А2/Б3 уже в службе),
   образец документа → структура шаблона (Б.2). Результат — предложением
   на акцепт, происхождение как заведено; аннотация после акцепта ложится
   в карточку с пометой «ИИ, акцептована».
4. Ш2 мастер-пути «Сложить своё» ведёт в этот механизм; карточка видна
   раскрытием у файла — по обновлённому эталону.

## Приёмка круга

- [ ] календарь второй вехи открывается на дате первой; обратный порядок —
      отказ сервером и формой с именами точек; снимок рядом с эталоном;
- [ ] правило порядка — одно на сервере, работает и в паспорте проекта;
- [ ] записка миссии загружается с карточкой через Ш2 и через «Исходные
      документы»; «Разобрать: профили стейкхолдеров» даёт пакет на акцепт —
      этим же закрывается ваш вопрос по запуску О-5;
- [ ] файлы попадают в резервную копию (сверить с О-18);
- [ ] снимки обоих мест рядом с эталонами, версия стенда тегом.
