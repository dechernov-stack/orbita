## §1 Процесс — мерами
- **Вид `task`** (`TS-NNNN`, схема `core/task`, V029): разрыв (`gap_ref` =
  стабильный id проверки готовности) + исполнитель + срок + комментарий.
  Статусной модели НЕТ вовсе — статус вычисляется закрытием разрыва
  (ручного «сделано» не существует). Тест: разрыв «риски заведены» закрылся
  созданием риска — задание стало «закрыто» без единого клика.
- **Назначение** — с готовности: «назначить…» на каждом открытом разрыве,
  «назначить группу · N…» на группе с подтверждением числом; исполнитель —
  из учёток (В3) либо именем при выключенном режиме; срок — DateInput.
  Право — руководитель и ведущий СИ (серверная проверка, тест на отказ
  специалисту); пачка идемпотентна (повтор не плодит дублей).
- **«Мои задания»** + счётчик «мои · N» в шапке (просроченное — красным,
  обновляется сразу после назначения): группы Просроченные → Активные →
  Ожидают → Закрытые; «к месту →» — один переход; «снять» — мягкая отмена.
  Руководителю — переключатель «все задания проекта».
- **Зависимости — вычисляемые, только данными** входов операции (карта фазы,
  `inputs` уже в реестре операций): задание на разрыв `op:X` при неготовом
  входе — «ожидает: ‹код · имя›», срок НЕ тикает; вход закрылся — задание
  активно само. Тест: op:О4 ждало «О3 · концепция»; ConOps доведён до
  Approved — активировалось без клика, и просрочка загорелась только тогда.
- **Порядок работы** (переделка мёртвого экрана операций): уровни ТОЛЬКО из
  данных (топологический порядок по входам) — параллельные рядом,
  последовательные ниже; на операции — состояние выхода, её задания с
  исполнителями, «к месту →». Мёртвая ссылка запрещена как класс: прогон —
  17 операций, 17 переходов, 0 мёртвых (безместной операции достаётся
  тихая подпись, не пустая строка).

## §2 Общие механики
- **`ui/RefChip`**: трассировка в раскрытии строки реестра и карточке —
  кликабельные чипы «ID · имя»; отменённая цель — зачёркнутый стиль с
  подсказкой. Прогон: чип источника из карточки требования увёл на экран
  цели/сервиса одним кликом.
- **`ui/RefPicker`**: все ссылочные поля форм (родитель, носитель, источник,
  норматив — через схему объекта) и распределение носителя — справочником:
  поиск по ID и имени, недавние сверху; свободный текстовый ввод ID умер;
  «создать и связать» кнопки нет — законных мест в этом заходе не было
  (ловушка 3).
- **Подсказки**: линт `tools/validate_tooltips.py` в `checks.sh` — маркерный
  элемент/кнопка-иконка без title = отказ сборки; найденные 7 мест закрыты
  расшифровками (статусные точки, маркеры операций, точки вех, рейка).
- **Сортировка заголовком** — один компонент `ui/sort.tsx`: постановка (все
  реестры шаблона), состав; реестр требований сортировал и раньше своим
  заголовком. В «Библиотеке» таблиц нет (полки — списки) — сортировке там
  нечего сортировать, сверх эталона не рисовал.
