# Данные для брифа Т-1: выгрузка 212 требований со стенда

Позиция дизайн-пакета «Требования» (ЗАДАЧА-ДИЗАЙН-ТРЕБОВАНИЯ.md).
Роль Code на этом шаге — заморозка поставок и живая выгрузка; вёрстка —
после заморозки эталонов.

## Что сделано

- Задание и эталон Т-1 (круг 3, `reference-req-registry.html`) заморожены
  в репо: `docs/tz/manual-run-2/` и `docs/ui/reference2/`.
- Выгрузка — `выгрузка-требований-PJ-0001.json` (667 КБ): все 212
  требований текущими версиями с полными документами (формулировка,
  показатель, категория, уровень, статус, обоснование, traces_up,
  verification_events, allocated_to, provenance), все 237 связей проекта,
  задевающих требования, и 13 связанных объектов с именами. Источник —
  БД живого стенда, без правок.

## Крайности — как просила задача

- **Длиннейшая формулировка**: `RQ-1907`, 275 знаков («…ретрансляция
  команды блокировки на другой КА группировки по РЧ-межспутниковой
  линии, если терминал C' вне зоны обслуживания наземного сегмента…»).
  Рядом `RQ-0905` (тоже 275) и `RQ-0407` (258). Короче всех `RQ-9005`
  (73), медиана — 156 знаков.
- **Сирота без носителя**: их 189 из 212. Носитель задан только у 23 —
  и все 23 распределены на один объект `IF-0001` «Радиолиния КА —
  станция». Компонентных распределений (CM-…) в проекте нет вовсе.
- **Требование с пятью детьми — в выгрузке НЕТ.** RQ→RQ-связей всего
  две (`RQ-1403`, `RQ-2104` — по одному ребёнку через derive);
  `traces_up` всех 212 требований смотрят в сервисы (SV-…), не в
  требования.

этим знанием:

## Вопросы владельцу

1. «Требование с пятью детьми» из входа задачи в живых данных
   отсутствует — максимум один ребёнок. Брать крайность из выгрузки
   как есть (один ребёнок), или сначала прогнать декомпозицию на
   стенде, чтобы появилась настоящая многодетность?
2. Смешение статусов, которым живёт эталон (Draft/Preliminary/Baseline
   вперемешку), в выгрузке отсутствует — всё Baseline. Для стенда
   плотности это не мешает, но состояния строк эталона живая выгрузка
   не покрывает — пометить в брифе как синтетические?
