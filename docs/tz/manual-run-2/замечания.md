# Второй проход владельца по ПМИ — замечания по ещё не переделанным экранам

Правило конвейера (ЗАДАЧА-CODE-КОНВЕЙЕР.md, «Живой стенд», п. 3): замечания
по экранам, до которых очередь вёрстки ещё не дошла, точечно не чинятся —
они складываются сюда и уходят входом в брифы и эталоны соответствующих
экранов. Замечания по уже переделанным экранам сюда не попадают: они
чинятся кругом вёрстки в рамках экрана.

Формат записи: дата · экран · замечание дословно · (при необходимости)
контекст воспроизведения.
