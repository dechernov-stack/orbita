# Задача Code: библиотека — полки, канал сбора, шаг Ш2 мастер-пути

Источник — `СТРУКТУРА-БИБЛИОТЕКИ.md`; при расхождении он старше. Задача
серверная плюс шаг Ш2 мастер-пути; кнопки на экранах приходят конвейером
(эталоны — от владельца процесса), старые экраны не трогаются.

## 0. Инвентаризация — до кода

Библиотека уже частично создана. Первый коммит — таблица «полка → что есть →
чего нет» по А1–Г2 против фактического состояния (`docs/library/INDEX.md`).
Дальше делается только недостающее.

## 1. Три формы хранения — не вид на каждую полку

1. **Типизированный объект** — там, где структура нужна ИИ и проверкам:
   `normative_document` (А1, есть — проверить), `mission_class` (Б4),
   `stakeholder_profile` (А2), `typical_risk` (Б3).
2. **Фрагмент** — один вид `library_fragment` на Б1, Б5, Б6, Б7 и заготовки
   Г1: содержимое — **пачка в формате импорта** (переиспользуем П1/П2
   целиком) плюс манифест: полка, класс миссии, счётчики состава,
   происхождение (проект, версия, автор, дата), признак обезличенности.
3. **Документ-файл** — А3 (даташит), А4 (аналог), В2 (образец): файл +
   карточка метаданных (источник, реквизиты, о чём); структурированная
   выжимка — позже, отдельным полем.

Ловушка: вид на каждую полку — расползание схем; три формы, не одиннадцать.

## 2. Канал «Сохранить как шаблон» — сервер

`POST /library/fragments/preview` из выборки (вид + идентификаторы либо
узел-корень поддерева) → **предпросмотр до записи**: что войдёт (счётчики),
какие внешние связи будут отрезаны — **поимённо**, какие значения станут
умолчаниями/TBD (карта замен — в теле подтверждения). Основания на А1 не
режутся. `POST /library/fragments` с картой замен — запись с происхождением.
Обезличивание молчком запрещено: без предпросмотра фрагмент не пишется.

## 3. Применение набора — минимум сейчас, остальное В4

Применение фрагмента = импорт его пачки в проект (готовым механизмом) +
связь «применяет» на библиотечную запись у каждого созданного объекта +
статус применимости (применено / с отклонением / неприменимо, обоснование
обязательно для двух последних). Подсветка новых редакций и матрица
соответствия — В4, сюда не лезть.

## 4. Мастер-путь: серверная часть и шаг Ш2

- Ш1: классы миссии — из Б4; выбор класса подставляет типовые ограничения
  класса (правятся). Ограничения проекта — хранятся при проекте, уходят в
  профиль.
- **Ш2: панель «Взять из библиотеки» строится из фактических полок по
  классу** — группы: типовые требования (Б1, система + элементные), каркас
  PBS (Б5), каркас WBS (Б6), типовые интерфейсы (Б7), комплект документов
  (В1), заготовки профилей (Г1). Счётчики — живые, из наполнения;
  «состав» раскрывает манифест. «Сложить своё» — файлы в материалы проекта
  (А-формы №3 в проектной области).
- Ш3: профиль собирается из заготовки Г1 + ограничений Ш1; предпросмотр
  промпта — готовым механизмом службы.
- Путь хранит своё состояние (шаг, выбранное), переживает выход и
  возвращение; «пропустить» ничего не блокирует.

## 5. Наполнение Pre-A (манифест §5 структуры)

- **Code сам**: Б4 класс «НОО · связь и IoT»; каркасы Б5/Б6 (типовой PBS
  НОО-IoT, типовой WBS программы); Б7 четыре интерфейса; Г1 заготовки
  профилей; Г2 глоссарий стартовый; В3 чек-листы из прил. G через профиль
  извлечения — **на акцепт владельцу**.
- **Службой на акцепт владельцу**: А2 профили стейкхолдеров и Б3 типовые
  риски — из записки миссии и регламентов.
- **Ждёт владельца**: А3 даташиты (что есть на руках), А4 аналоги.
  Не выдумывать за него.

## 6. Приёмка

- [ ] `docs/library/INDEX.md` — полки против факта, недостающее названо;
- [ ] предпросмотр сохранения показывает резку поимённо; фрагмент без
      подтверждения не записан;
- [ ] сохранённое с узла поддерево применяется в **другой** проект и даёт
      работающий состав со связями «применяет» и происхождением;
- [ ] Ш2 показывает живые наборы с фактическими счётчиками; «взять»
      создаёт экземпляры; «состав» раскрывает манифест;
- [ ] применимость с обоснованием обязательна для отклонений;
- [ ] отчёт — мерой: сколько полок наполнено, что ждёт акцепта владельца,
      что ждёт его материалов.

## Ловушки

1. Вид на каждую полку — три формы хранения, не одиннадцать схем.
2. Обезличивание или резка связей молчком — только через предпросмотр.
3. Полный tailoring (редакции, матрица соответствия) — В4, не сейчас.
4. Кнопки на старых экранах — сервер сейчас, UI конвейером по эталонам.
5. Каркас WBS зеркалом PBS — прежний запрет действует и в библиотеке.
6. Наполнение А3/А4 фантазией — ждёт владельца, пустая полка честнее.
