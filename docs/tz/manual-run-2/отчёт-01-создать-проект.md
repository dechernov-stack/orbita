# Отчёт конвейера · экран №1 «Создать проект»

Эталон: `docs/ui/reference2/reference-create-project.html` (круг 1).
Версия стенда: тег `stand-screen-01` (выкачено на живой стенд, база не сбрасывалась).

## Что сделано

- Отдельный экран `web/src/screens/NewProject.tsx`; врезка создания в
  «Портфеле» удалена, кнопка «Создать проект» ведёт на экран.
- Оболочка (везде): рейка 68 px, иконки эталона + подпись целиком под
  иконкой; на экране создания панели раздела нет, в шапке — крошка
  «Портфель / Новый проект» (первая установка — «Первый проект»).
- Все четыре состояния — один экран; тексты дословно из эталона.

## Проверка поведения (все — руками, снимки в сессии)

1. Кнопка неактивна при пустом имени; Enter создаёт; двойное нажатие
   отсечено синхронным стражем — второй проект не создаётся.
2. Смена фазы меняет ленту точек и строку «после создания…».
3. Даты — в раскрывашке, необязательны, «дата не задана» без предупреждений.
4. Совпадение имени — жёлтое предупреждение с id и фазой существующего
   (проверено на живом стенде: PJ-0001, фаза Phase A); создать можно.
5. Отказ сервера — красное состояние дословно по эталону; введённое
   остаётся в форме (проверено гашением api на одноразовом стенде).
6. Первая установка — вводная строка, «Первый проект», без «Отмены»
   (одноразовый стенд с пустой базой; основная база не сбрасывалась).
7. «или загрузить проект из файла» → экран «Загрузка пачкой».
8. После создания — жизненный цикл нового проекта.

## Расхождения с эталоном (поимённо)

1. Шапка: справа живое поле «Инженер: [ввод]» (общий механизм авторства)
   вместо статичного «Инженер: Чернов Д.» эталона. Шапка — общая оболочка,
   не переделывалась.
2. Кнопка «Создать проект» дополнительно гаснет при пустом поле «Инженер»
   (подсказка «представьтесь в шапке»): сервер отклоняет изменение без
   автора. В эталоне такого состояния нет.
3. Состояния 3–4 эталона не показывают ленту/раскрывашку/ссылку загрузки —
   истолковано как сокращение стенда: на живом экране элементы присутствуют
   во всех состояниях, кроме первой установки (там — по эталону S2).
4. Содержательный отказ сервера (не 502/503/504 и не обрыв сети)
   показывается его собственным текстом в том же красном блоке; эталон
   покрывает только «сервер недоступен».
5. Иконки «Концепция» и «Инструменты» дорисованы в стилистике эталона
   (в эталоне пять разделов, в системе семь).

## Вопросы владельцу

1. Ввод дат — строка «дд.мм.гггг» по эталону. Непарсимая строка в паспорт
   не отправляется (веха остаётся без даты), состояния ошибки формата в
   эталоне нет. Нужно ли оно — или календарь, как было в прежней врезке?
2. Пустой «Инженер»: оставить гашение кнопки с подсказкой — или добавить
   в эталон состояние отказа «представьтесь»?
