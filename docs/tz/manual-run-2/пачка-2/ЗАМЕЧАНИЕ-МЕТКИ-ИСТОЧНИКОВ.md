# Замечание к пачке-2 (круг): семантика меток источников — дословно

## Дефект

Расшифровка меток в системе не совпадает с авторской. Легло (проверено):
правило 12 промпта (`prompt-package-kinds.json:177`), комментарий
`DocumentParse.kt:82`, вероятно — раздел шаблона `DT-9001` на полке и
подсказки чипов урожая.

**Верная семантика (дословно из записки владельца):**
- **[И]** — внутренний документ (наш материал);
- **[В]** — внешний источник, проверенный на указанную дату;
- **[П]** — предлагаемая цель или инженерно-финансовое допущение,
  требующее подтверждения.

Нынешнее «[В] — вывод автора» перевёрнуто: внешний проверенный факт
станет авторским мнением; при живом вызове разбора это исказит
`source_mark` всей нормативной базы.

## Правка

1. Заменить расшифровку во всех местах: правило 12, комментарий
   разборщика, раздел «Обозначения источников» шаблона `DT-9001`
   (сид + обновление полки на стенде), тултипы/чипы урожая.
2. Формулировка запрета в правиле 12 остаётся, но точнее:
   «[П]-допущение не выдавай за факт; [В] — внешний проверенный факт,
   не мнение».
3. Переразбор документов не нужен (метка переносится символом), но
   версию правил промпта поднять, чтобы отпечаток различал редакции.

## Мера

`grep -rn "вывод автора"` по репозиторию → 0 вхождений; раздел шаблона
на стенде совпадает с запиской владельца дословно; **Е6 [Ж] — только
после этой правки** (иначе живой урожай ляжет с перевёрнутой
достоверностью).
