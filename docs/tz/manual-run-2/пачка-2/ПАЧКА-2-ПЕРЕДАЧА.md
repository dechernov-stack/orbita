## Сквозная мера пачки

промпте сами (тип постановочный), полоса ведёт: разобрать → акцепт →

генерация разблокирована; анкеты Pre-A видны приглашением и **не горят**
разрывами железа. Ни одного тупика «загрузил и смотри».
