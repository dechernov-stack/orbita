# Задача Code: процесс к точке, зависимости, общие механики (спринт MVP)

Один заход, порядок разделов = порядок исполнения. Основа:
`БЛОКЕРЫ-МВП.md`, `РЕШЕНИЕ-ПРОЦЕСС-К-ТОЧКЕ.md`.

## 0. Блокеры прохода — первыми

**Б-01** «Вставить пакет» на экране предложений (JSON, вид из пакета,
источник «пакет», модель не зовётся). **Б-02** «Отменить» для объектов
постановки (мягко, историей; массово с числом) + разовая чистка мусора
первой попытки владельца. Подробности — в реестре блокеров.

## 1. Процесс: задания и порядок операций

1. **Вид `task`**: цель (разрыв/группа разрывов), исполнитель (учётка),
   срок, комментарий. Статус **вычисляется** закрытием разрыва — ручного
   «сделано» нет. Назначение: с готовности и с разрыва, массово — с
   подтверждением числом; право — руководитель и ведущий СИ (реестр прав).
2. **`/views/my-tasks`** + счётчик «моих» в шапке: разрывы участника со
   ссылками «к месту», просроченное первым.
3. **Порядок операций — данными фазы** (карта операций уже есть): у
   операции — входы (операции-предшественники / артефакты, по регламенту:
   О2–О12 параллельны, О13–О17 строго цепочкой). Никакой параллельности
   «рисунком» — только данными.
4. **Зависимости заданий — вычисляемые.** Задание на разрыв операции,
   вход которой не готов, — состояние **«ожидает: ‹предшественник›»**:
   срок не тикает, просрочка не горит; вход закрылся — задание стало
   активным **само**, без единого клика. В «Моих заданиях» — группа
   «Ожидают» отдельно от активных.
5. **Экран порядка работы к точке** (переделка мёртвого): операции фазы —
   последовательные цепочкой, параллельные рядом; на каждой — счётчик её
   разрывов, исполнители, выход-артефакт ссылкой к месту. **Мёртвая ссылка
   запрещена как класс**: строка либо ведёт к месту, либо тихая подпись
   «место появится с волной N».

## 2. Общие механики — мелкое, но общесистемное

1. **Ссылки кликабельны.** Любое ссылочное поле в карточках, раскрытиях и
   формах — компонент `ui/RefChip`: «ID · имя», клик — переход к объекту;
   отменённый объект — стиль разрыва (зачёркнутый, с подсказкой), не 404.
2. **Ввод ссылок — справочником.** `ui/RefPicker`: поиск по ID и имени,
   фильтр по виду, недавние; «создать и связать» — только явной кнопкой
   внутри пикера, где это законно. Все места ввода родителя, носителя,
   источника, норматива переходят на пикер; текстовый ввод ID умирает.
3. **Подсказки при наведении.** `ui/Tooltip`; обязательны на: маркерах
   помет (полная расшифровка), статусных точках, счётчиках, обрезанных
   текстах (полный текст), иконках без подписи, зачёркнутых датах
   (причина), тихих дефисах (почему пусто законно). Правило: **элемент без
   текста обязан нести подсказку** — линт-проверка в `checks.sh`
   (интерактивный/маркерный элемент без title — отказ).
4. **Сортировка заголовком** — один компонент: клик — сортировка, повтор —
   реверс, стрелка видима; во все таблицы; клиентская по загруженному.

## 3. Приёмка

- [ ] Б-01/Б-02: владелец проходит А7–Б4 пакетами; мусор вычищен;
- [ ] назначение: три разрыва двум участникам с готовности; каждый видит
      свои в «Моих», доходит до места одним переходом; закрытие разрыва
      закрыло задание без клика;
- [ ] зависимость: задание на разрыв О9 при незакрытом входе О5 —
      «ожидает: О5»; закрытие входа активировало само (тест);
- [ ] порядок работы: некликабельного не осталось — переход или тихая
      подпись; снимок;
- [ ] ссылка «источник» в карточке требования ведёт в нужду кликом;
      «декомпозировать» и распределение — через пикер;
- [ ] тултипы на пометах и дефисах реестра — текстом расшифровки; линт
      «элемент без подсказки» в сторожах;
- [ ] сортировка — в реестре, постановке, составе, библиотеке.

## 4. Ловушки

1. Статусы заданий руками — только вычисляемые (разрыв, вход).
2. Зависимость галочкой — только от данных входов операции.
3. RefPicker со свободным текстом — «создать» лишь явной кнопкой.
4. Тултип, обрезающий текст, — подсказка несёт полный.
5. Параллельность рисунком без данных — порядок только из карты фазы.
6. Уведомления, обсуждения, календарь — не в этом заходе (граница В3).
