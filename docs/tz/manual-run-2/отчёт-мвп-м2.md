# Отчёт: сравнение построений (МВП-М2)

Входы: `ЗАДАЧА-CODE-СРАВНЕНИЕ.md` + `МЕТРИКИ-ПОСТРОЕНИЙ.md`. Выкат: живой
стенд накатом, тег `mvp-m2-01`. Тесты: `CompareMetricsTest` + полный прогон
`--rerun-tasks` зелёные; приёмка — сквозным прогоном на одноразовом стенде
из копии прод-базы (снимки `мвп-м2-*.png`).

## §1 Варианты
Вариант — обычный объект constellation (версии, происхождение); список на
экране, в сравнение — выбранные 2–5. «Рабочий» — единственный: ссылка
сценария (его считает карта и показатели); пометка ★ вычисляется, смена —
явным действием со сменой ссылки с основанием (проверено прогоном).

## §2 Метрики — 14 по документу, из одного интеграла
- **А1–А6** — из того же интеграла видимости §5 (второго движка нет):
  покрытие по классам A′/B′/C′ взвешено спросом сетки; max gap — худшая
  ячейка; **ревизит — 75-й перцентиль** (тест: на распределении с хвостом
  10×60с + 1×3600с среднее 382с валит порог «5 минут», перцентиль честно
  даёт 60с — хвост виден отдельной метрикой max gap); отклик E[gap²]/2T;
  латентность store-and-forward = ожидание пролёта + сброс тем же КА на
  станцию (по расписаниям того же интеграла); запас ёмкости — минимум по
  зонам класса, единица «проходо-мин/сообщение» (ёмкости канала в модели
  КА нет — при появлении умножается тем же полем).
- **Б7–Б8**: партии — несовместимость (наклонение × высота); время
  развёртывания — кампании + RAAN-развод прецессией; прокси-стоимость с
  коэффициентом попутности типа орбиты. Все коэффициенты — ДАННЫМИ
  (`compare-config.json`; файл в каталоге файлов стенда перекрывает дефолт
  без пересборки — тест меняет коэффициент файлом и видит новую цену).
- **В9–В10**: деградация — повторный интеграл без одного КА худшей
  подгруппы (Δ max gap худшей зоны; между вариантами различна — тест);
  Δv поддержания таблицей высот, увод — decayYears/deorbitDeltaV против
  норматива 25 лет.
- **Г11–Г14 — только прокси, с пометкой в выдаче**: тень/β — прямая
  астрономия по подгруппам (терминаторная ССО LTAN 6:00 — тень <10%,
  наклонная 52° — >25%: мера документа, тест); радиация — таблица классов
  (данные); станции — жадный перебор каталога площадок РФ до целевой
  латентности; окно/доплер — из геометрии.

## §3 Экран
Таблица: строки — варианты, колонки группами А/Б/В/Г («прокси» — в
заголовке группы и в подсказке каждой колонки: чем посчитано); сортировка
заголовком; **Парето** считает сервер (оси переключаемы: ёмкость · max gap
· стоимость · развёртывание · деградация), недоминируемые подсвечены ◆;
**пороги — фильтром**: строки-пороги с подписью (RQ-…), отсеянные — в
перечне «кто и по какому порогу выбыл» поимённо. Итогового балла нет.

## §3.5 Вставка в AoA
Расчёт сохраняется хранимым результатом (kind `constellation_compare`,
версии входов — TZ-COM-006); рендер «Отчёта о концепции миссии» (Д2, §2
AoA) вставляет последнюю матрицу сравнения; выпуск фиксирует снимок телом.
Проверено прогоном: вставка видна в разделе AoA.

## Мера документа — на живой сетке спроса (1208 ячеек)
Walker 40/5·550 против смеси 4×52°+3 ССО: Walker — покрытие A′ 94.9%,
но max gap 1440 мин (высокоширотная ячейка спроса за сутки не увидена) и
партий 1; смесь — покрытие ниже (14 КА против 40), но max gap 250 мин,
латентность севера 148 мин против 955, энергорежим терминаторной ССО без
затмений (0% против 37%), партий 2. Различимо таблицей, без балла.
