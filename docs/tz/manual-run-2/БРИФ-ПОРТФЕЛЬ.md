# Бриф экрана: Портфель

## 1. Роль и момент
Любой вошедший — это входная дверь системы. Моменты: утренний вход
(«что нового и где горит»), переключение между проектами, первая установка.

## 2. Работа
(а) Открыть свой проект одним действием; (б) понять состояние каждого за
взгляд: фаза, ближайшая точка и сколько не закрыто, возвраты; (в) продолжить
брошенный путь начала; (г) создать или загрузить проект.

## 3. Вопросы, по важности
1. Где мой проект и что в нём горит? 2. Что изменилось с прошлого входа
(последняя активность)? 3. Какие проекты в каких фазах? 4. Как создать?

## 4. Данные и крайности
Проектов 1–20; имя до 120 знаков; фаза; ближайшая точка + счётчик
незакрытого; действующий возврат (0–1); путь начала (не начат / шаг N из 3 /
пройден); последняя активность (кто, когда); руководитель. Крайности:
0 проектов (первая установка); 1 проект; имя в три строки.

## 5. Агрегация и иерархия
**Строки, не плитки** — плотность и сравнимость; сортировка по последней
активности; при ≤20 проектах никакого группирования и поиска. Возврат —
красный маркер в строке, не отдельная зона.

## 6. Действия
Клик по строке — открыть (вся строка — цель); «Создать проект» — первичная;
«или загрузить из файла» — ссылкой; «продолжить» — чипом в строке пути.

## 7. Состояния
Первая установка (приветствие + создать/загрузить, без пустой таблицы);
обычное; строка с возвратом; строка с незавершённым путём.

## 8. Чего нет
Дашбордов и графиков программы (отдельный экран, по потребности); архива;
ролей и приглашений (В3 живёт в проекте); фильтров и поиска до 20 проектов.
