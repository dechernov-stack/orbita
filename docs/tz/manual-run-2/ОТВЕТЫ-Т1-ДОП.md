# Ответы: открытые вопросы Т-1 (дополнение к РЕШЕНИЯ-Т1)

## 1. Плотность — повтор из РЕШЕНИЯ-Т1 (файл не доехал, идёт этой передачей)

Принять 27. Строку мельче 26 px не жать; тулбары ужать на 2 px, если без
тесноты. Мера: **≥27 строк на 1440×900, ≥33 на 1920×1080, обрезок 0.**

## 2. Журнал автораспределения на корень

- **Автор — человек, чьё действие породило корень** (создал корень кнопкой,
  взял каркас PBS в Ш2), не служебная учётка: автораспределение — следствие
  его осознанного шага. Помета в записи: «автоматически, по правилу уровня
  проекта».
- **Одна сводная запись**, не N строк спама: «Распределено на корень:
  8 требований уровня проекта» с перечнем в раскрытии.
- Происхождение связи: `allocated_to.provenance.source = "auto_root"` —
  отличимо от ручного распределения навсегда.
- **Отмена симметрична**: отмена взятия каркаса / удаление корня гасит
  автосвязи вместе с корнем — той же сводной записью; ручные распределения
  (если успели переехать) — 409 с перечнем, как заведено в канале.

## 3. Имя группы системных сирот

**«Без носителя»**, первой среди групп системного уровня — тем же именем,
что чип-фильтр («Без носителя (системные)» в чипе, короткое «Без носителя»
в заголовке группы: уровень ясен из контекста группировки). Заголовок —
нейтральным стилем групп, тревогу несут чип-счётчик и приглашения
«распределить» в строках. Прежнее «Не распределено» не возвращать ни в
каком виде.
