## Несистемный остаток — З-У и дизайн (не чинится точечно)

### Дизайн (ждёт эталонов Design — поток 3 пакета)

1. Карточка объекта — сырая форма по схеме: без группировки полей по
   смыслу, подформы событий верификации громоздки (NEXT, 2026-08-25).
   → эталон «Реестр требований + инспектор» (О-12).
2. Экран «Документы»: просмотр выпуска, печатная форма — В1.4, ждёт
   эталона печатной формы.
3. Правка авторского текста раздела (В1.2 серверно готова) — UI ждёт
   того же эталона Design.
4. Замечания дизайна всего приложения, отложенные владельцем до конца
   прогона, — конвейером по эталонам, не точечно.

### З-У (улучшения, в очереди волн)

5. Автопростановка происхождения из документа-источника (ADR-030):
   материал службы из SD-NNNN не несёт provenance.import автоматически.
6. Отчёт по прогону: таблицы §4–§5 ПМИ по журналу сессии,
   `прогон-<дата>.md` — вход подготовки независимой сессии.
7. Сводка «состояние модели» в промпте службы — агрегат вместо листинга
   (вопрос круга О-4, ждёт решения владельца).
8. Перенос роли («Ты — инженерная служба…») из модельной преамбулы в
   профиль (вопрос круга О-4).
9. Файлы-вложения (А3/А4/В2 «документ-файл») — blob-хранилище, вопрос
   владельцу (INDEX библиотеки).
