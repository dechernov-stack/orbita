# Реестр долгов, перенесённых через KDP B (liens)

Проект **PJ-0001 «Национальная спутниковая IoT платформа»** прошёл все шесть
контрольных точек Формулирования (internal_review → MCR → KDP-A → SRR →
SDR → KDP-B). Решение KDP B — Approve; настоящий реестр фиксирует, **с чем
именно** проект входит в Phase B: пройденная точка не отпускает грехи, она
их документирует.

Снят по живой модели в момент прохождения (2026-08-25). Категории — по
источникам системы; каждый пункт проверяем повторным запросом.

## 1. Отведённые правила качества (9 вейверов)

Девять требований несут вейвер одного и того же правила
«формулировка говорит „в пределах" (range), а оператор — eq»:

RQ-0409, RQ-0509, RQ-0809, RQ-1009, RQ-1109, RQ-1207, RQ-1809, RQ-2209,
RQ-3208 — обоснование инженера: полоса задана допуском вокруг номинала,
по смыслу «ровно» (одна зона обслуживания).

*К Phase B:* девять одинаковых вейверов — сигнал, что правилу нужен
разбор «в пределах ± допуск» как самостоятельный образец оператора eq,
а не девять отводов. Кандидат в правку правил качества.

## 2. Пустые разделы действующих документов (24 раздела в 7 документах)

Модель пока не несёт видов, из которых эти разделы собираются:

| SEMP (Д2) | §3 Организация технических работ; §4 Применение процессов; §6 Tailoring; §7 Инструменты и среда; §8 Согласование |
| План рисков (Д7) | §1 Процесс управления рисками; §5 Отчётность |

Плюс спецификация требований: не заполнены «применимые документы» паспорта.

*К Phase B:* организационные разделы (SMA, закупки, персонал, согласование)
требуют либо новых видов модели, либо решения «эти разделы ведутся вне ИС».

## 3. Устаревшие выпуски (4 документа)

Модель ушла вперёд после последнего выпуска: **ConOps, План проекта, SEMP,
Formulation Agreement** — слепок разошёлся. Перевыпустить при входе в
Phase B (кнопка сама активируется — слепки разные).

## 4. План Phase B–F без дат (7 вех)

PDR, CDR, SIR, ORR, FRR, Launch, EOM — добавлены в единый ряд контрольных
точек, но ни дат-якорей, ни длительностей этапов не заданы: график за
KDP B существует составом, но не календарём. Задать длительности на ленте
цикла — первым делом Phase B.

## 5. Открытые риски (5)

RSK-0001…0005 — все в статусе open со стратегиями mitigate и сроками
мероприятий в конце 2026 — начале 2027. Перенос в Phase B штатный
(реестр живёт), но сроки мероприятий уже требуют актуализации.
