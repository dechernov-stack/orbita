Т-1 · Реестр требований — эталон, круг 4

Решения круга: боковой панели нет — требование раскрывается строкой вниз (суть без ухода), полная анатомия — карточкой на всю рабочую область с листанием по реестру. Тулбар — три строки, у каждой одна работа: раздел и главное действие · форма данных (Дерево/Плоско × Группировка по критерию) с видами и поиском · счётчики разрывов. Группы схлопываются шевроном; сироты — первой группой целиком. Ребёнок в дереве — с отступом, без дублирования строки (связь для показа). Конфигуратор колонок совпадает с фактом таблицы. Вторичные действия — в меню «⋯». Конфигуратор колонок — прежний, ⚙ Вид. Данные — пилот «Ротор-Л», статусы смешаны для показа; сироты настоящие. Пометы — квадратики у статуса; разрывы — счётчики-фильтры.
