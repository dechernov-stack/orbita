Т-2 · Карточка требования в состояниях — эталон, круг 1

Пять трудных состояний карточки из Т-1. Правила: изменение базированного — только с основанием (v+1); конфликт пересчёта показывает «было/стало/что делать» и не решается молча; разрыв — приглашение с действием, не прочерк; откат — новая версия, история не переписывается; уровень проекта держится за нужду (носитель — механика, придёт с корнем автоматически); настоящий сирота — системное требование без элемента. Пометы после доработки семантики — исключения, и карточка обращается с ними как с событиями.
