Компонент даты — эталон оболочки (закрывает последний нативный контрол)

Правила: ручной ввод дд.мм.гггг равноправен календарю; пустая дата законна («дата не задана»), очистка — крестиком; календарь открывается от опорной даты (предыдущая заданная веха — правило круга 2), опорный день подсвечен серым; дни раньше опорного — недоступны с зачёркиванием, попытка ручного ввода даёт отказ с именами точек; клавиатура: ↑↓ день, PgUp/PgDn месяц, Enter выбор, Esc закрыть. Никаких системных date input.

Применения сразу: даты вех в создании проекта и паспорте (опора — предыдущая веха), дата документа в карточке источника (без опоры), даты событий верификации.

Отказ порядка — тем же текстом, что серверный (одно правило, круг 2).
