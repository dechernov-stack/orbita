# Снимки экранов на демо-проекте

Сняты браузером на реальных данных API (`npm run check:screens`), а не собраны
из макетов. Модель — демонстрационный проект «Орбита-IoT».

| Файл | Экран | Что видно |
| --- | --- | --- |
| `screen3.png` | 3 и 3б — требования | дерево с отступами, структурное условие с подписью единицы, свёртка бюджета с остатком, карточка требования справа |
| `screen11.png` | 11 — спецификация элемента | требования элемента, источник с видом декомпозиции, прогресс событий V&V |
| `screen7.png` | 7 — сравнение вариантов | роза KPI с подписанным набором нормировки, фронт Парето |
| `screen12.png` | 12 — система в целом | бюджеты, состояние верификации, матрица рисков 5×5, перечень проблем |
| `screen6.png` | 6 — баллистика | глобус CesiumJS, трассы из CZML-потока сервера |

На снимке экрана 12 видна несимметричность матрицы рисков: строка последствий 5
красная начиная с вероятности 1, а строка последствий 1 доходит до жёлтого лишь
при вероятности 5. Редкое тяжёлое событие не теряется среди частых мелких.

Демо-проект намеренно неидеален — на снимке 12 перечислены шесть проблем:
требование без закрывающего события, три риска к эскалации, два элемента
без требований. Витрина, где всё зелёное, не показывает, как система ловит
проблемы.
