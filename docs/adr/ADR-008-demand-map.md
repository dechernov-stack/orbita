# ADR-008. Трёхслойная карта спроса

**Статус:** принято (Р8)
**Решение:** карта спроса строится тремя слоями: (1) плотность населения на сетке ~100×100 км × коэффициент «терминалов на жителя»; (2) единичные объекты и маршруты вне корреляции с населением (СМП, инфраструктура малонаселённых районов); (3) сценарная библиотека под реальные бизнес-кейсы.

**Основание:** нулевое приближение доступно сразу (открытые датасеты населения на сетке), содержательная карта появляется до получения клиентских данных.

**Следствия:** оценка качества построений взвешивается по спросу — построения, покрывающие незаселённые области, не получают паразитного преимущества; слой единичных объектов удерживает ненулевой вес стратегических малонаселённых районов.
