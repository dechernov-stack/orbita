# ADR-034. Библиотека запрашивает данные: анкеты характеристик носителей

**Статус:** принято (Ф-06 пачки-1 фиксов прогона)
**Контекст:** инженер открывал «Модель аппарата» и, по словам владельца,
«стоял и смотрел на неведомые идеи»: система ждала ввода молча. Какие
характеристики платформы ей нужны, в каких единицах, что обязательно —
знал только код формы и схемы контрактов. Незаполненное не было видно
нигде: модель просто не считалась.

## Решение

### 1. Анкета характеристик — объект полки, а не форма в коде

Вид `property_form` (полка LIB): роль носителя (**платформа · полезная
нагрузка · терминал · наземная станция**), класс миссии и перечень полей.
Поле несёт: машинный ключ, имя инженеру, **единицу из справочника**,
обязательность, подсказку (термом глоссария — механика Ф-03 — либо своим
текстом) и, если поле уже живёт в модели, адрес значения (`target`).

Новое поле или новая роль — правка анкеты на полке, не правка кода.

### 2. Запрос данных = анкета, наложенная на модель

`GET /views/data-requests` возвращает анкеты класса миссии с состоянием
каждого поля: заполнено или нет, чем именно и **откуда** — из модели
(`model`) или из даташита (`harvest:SD-NNNN · блоки`). Клиент ничего не
вычисляет: заполненность и счётчики считает сервер.

### 3. Три пути заполнения — все явные на форме

- **рукой** — форма модели аппарата;
- **типовым с полки** — компоненты библиотеки;
- **даташитом** — разбор документа (Д1/Д2) предзаполняет поля: класс
  урожая `property` несёт `form_field` — имя поля анкеты, — и значение
  приходит с координатой блока. Инженер сверяет и принимает; выдумок нет,
  происхождение при каждом значении.

### 4. «Чего не хватает» — вычисляется, а не забывается

Незаполненное обязательное поле становится проверкой готовности
`data_requests` («данные не заданы») с местом починки «Модель аппарата».
Проверка не блокирует ворота — это предупреждение фазы: она называет
пробел, а решение остаётся за инженером.

## Приёмка

`DataRequestsTest`: в пустом проекте анкеты приходят по четырём ролям с
единицами и подсказками; подсказка поля берётся из глоссария, когда анкета
назвала терм; заполненное в модели поле спрошенным не считается и несёт
источник `model`; даташит предзаполняет чувствительность и диапазон частот
с координатами блоков `t1#3` и `b4`; незаполненное обязательное даёт разрыв
готовности с местом починки.
