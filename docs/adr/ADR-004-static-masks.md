# ADR-004. Режимы КА — статические географические маски

**Статус:** принято (Р4)
**Решение:** расписание режимов КА в первой очереди задаётся статическими географическими масками, генерируемыми из карты спроса. Динамический планировщик — интерфейс-заглушка без реализации.

**Основание:** динамическое планирование (по очередям, энергобалансу, приоритетам) почти наверняка потребуется во второй очереди; цена интерфейса мала — одна функция «сценарий → расписание режимов».

**Следствия:** модель и Монте-Карло не зависят от способа формирования расписания; переход к динамике не требует пересмотра модели. Это единственное осознанное отступление от принципа лёгкой модульности без интерфейсов.
