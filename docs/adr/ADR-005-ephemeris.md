# ADR-005. Обязательное знание эфемерид терминалами

**Статус:** принято (Р5)
**Решение:** терминалы всех классов знают эфемериды и передают по расписанию пролётов. КА ведёт широковещательный маяк альманаха/расписания по абонентской нисходящей линии. Передача «вслепую» моделируется как деградированный режим (устаревший альманах), не как штатный.

**Основание:** слепая передача расходует энергию терминала впустую и засоряет канал. Референс — коммерческая практика Lacuna Space (LoneWhisper): спутники широковещательно передают времена пролётов, узел просыпается только к пролёту.

**Варианты формата маяка (открыто):** расписание пролётов / полный альманах / компактная динамическая модель орбиты, по которой терминал сам генерирует элементы и считает пролёты стандартным пропагатором (подход US 10,877,158) — последний вариант снижает частоту маяка и увеличивает допустимый возраст альманаха ценой вычислений на терминале.

**Следствия:**
- нисходящая линия нагружена маяком везде, где есть датчики (включая ячейки без спроса на данные) — учитывается в энергетике КА и бюджете линии по худшему терминалу на краю зоны;
- возраст альманаха связывает качество сервиса с частотой пролётов: редко посещаемая ячейка → риск деградации.
