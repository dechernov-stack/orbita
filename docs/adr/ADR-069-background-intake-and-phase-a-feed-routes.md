# ADR-069. Разбор фоновой задачей; маршруты записей A4/A5; EXP-2A — помета

**Статус:** Принято · 2026-09-10 (предусловия ПМИ-5)
**Контекст:** `ПМИ-5-СЦЕНАРИЙ` §«Стенд. Предусловия Code»: «разбор — фоновой
задачей; маршруты функций/обменов/цепочек (A4/A5) — есть или названы
отсутствующими; позиции EXP-2A — помета, точку не держат». Находка 10.09:
`HttpServer` api однопоточный, разбор ТЗ живой моделью (минуты) блокировал
стенд, healthcheck падал.

## Решения

**1. Разбор — фоновой задачей; в фоне живёт только сеть.** Сервер остаётся
однопоточным (один `Connection` контуров v2 не потокобезопасен), поэтому
работа разбора разрезана по границе базы: промпт собирается на потоке
запросов (`Atomizer.prepare`), сетевой вызов провайдера идёт в фоновом потоке
(`AiService.askDetached` — без чтения и записи базы), а ответ применяется —
журнал вызова и приём фактов (`Atomizer.apply`) — снова на потоке запросов,
при следующем обращении к заданию. Реестр заданий (`AtomizeJobs`,
`BackgroundAtomizer`) — в памяти api: перезапуск стенда теряет идущее
задание, и опрос честно говорит «повторите разбор». Ответ, уже лежащий в
журнале по отпечатку промпта, применяется сразу — фон не нужен.
Маршруты: `POST /v2/intake/atomize {…, background: true}` → 202 `{job,
status: running}` (201 `done`, если из журнала); `GET /v2/intake/jobs/{id}`
— опрос с применением; `GET /v2/intake/jobs` — список. Синхронный разбор
остаётся (скрипты, тесты). Поле знаний в клиенте разбирает фоном и
опрашивает раз в три секунды, показывая задание и секунды.

**2. Записи A4/A5 — маршрутами реестра.** `POST/GET /v2/functions`,
`/v2/exchanges`, `/v2/exchange-items`, `/v2/budgets`,
`/v2/logical-components`: обязательные поля названы, ссылки кодами
разрешаются в id и проверяются по виду до записи — ссылка в пустоту
отказывает. Условия сцен читают эти записи; прогон `walk_scenes --phase-a`
кормит функции на элементы, обмены с элементами обмена на стыках, бюджеты
с политикой резервов, логический компонент и сценарные требования цепочкам.

**3. Позиции EXP-2A — помета.** Пока полка Романова не несёт позиций
экспертизы SRR, условие `expertise_positions_reviewed:SRR` в A12 не держит
сцену (`blocking: false`): оно видно словами «полка не транскрибирована», а
точку и сцену держит EXP-2B.

## Последствия

- Многопоточный сервер по-прежнему открытый вопрос: фон снимает блокировку
  только у разбора; печать PDF и «Написать связно» остаются синхронными
  (секунды, не минуты).
- Тесты: `BackgroundIntakeTest` (задание идёт → база пуста → ответ
  применён при опросе; отказ провайдера назван; ответ из журнала — сразу),
  `ArchFeedTest` (маршруты и отказ на ссылку в пустоту).
