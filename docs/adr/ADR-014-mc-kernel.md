# ADR-014. Ядро Монте-Карло: аналитика на ячейку + розыгрыш по представителям, счётчиковый ГПСЧ

**Статус:** принято
**Контекст:** полный перебор сообщений на эталонном сценарии даёт ~4·10¹¹ событий — нереализуемо. Одновременно требуются побитовая воспроизводимость (TZ-FLW-002) и параллельность ради бюджета времени (TZ-COM-004).

**Решение:**
1. Детерминированная аналитика на ячейку и пролёт: предложенная нагрузка, вероятность коллизии и ёмкость из адаптера, замыкание бюджета линии.
2. Монте-Карло только по существенно случайным измерениям: всплески коррелированных событий, цепочки повторов с эфемеридным backoff, бюджет времени реакции C', деградация терминалов по возрасту альманаха. Вместо перебора всех терминалов — выборка представителей с весами по численности популяции (~4·10⁹ событий, ≈10 с на 8 ядрах).
3. Счётчиковый ГПСЧ (Philox/Threefry): поток адресуется парой «зерно × индекс реализации × индекс сущности».

**Основание:** счётчиковый ГПСЧ снимает конфликт воспроизводимости и параллельности — результат не зависит от порядка выполнения потоков, поэтому распараллеливание не влияет на побитовое совпадение.

**Следствия и риски:**
- выборка представителей смещает хвосты распределений: требуется контроль сходимости по числу представителей и сверка с полным перебором на малом сценарии;
- аналитический «скелет» может скрыть эффект перегрузки — контролируется случаем TZ-FLW-004 (нелинейный рост повторов при снижении ёмкости).
