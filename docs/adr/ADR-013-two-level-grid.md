# ADR-013. Двухуровневая сетка видимости

**Статус:** принято
**Контекст:** прямой перебор пар «КА × ячейка спроса × шаг времени» на эталонном сценарии даёт ~10¹⁰ проверок (≈2 мин) — половина бюджета TZ-COM-004 уходит только на геометрию.

**Решение:** видимость рассчитывается на грубой сетке (~800×800 км), затем уточняется до ячеек спроса по границе зоны обслуживания из `service-zone`.

**Основание:** footprint LEO шире 2000 км — существенно больше грубой ячейки, поэтому огрубление не теряет пролёты, а лишь смещает границы, которые всё равно уточняются вторым проходом. Оценка: ~6·10⁶ пар вместо ~10¹⁰, около 0,1 с.

**Следствия:**
- ошибка у края footprint контролируется сверкой с эталонами TAT-C (TZ-BAL-008, порог 2% по покрытию);
- размер грубой ячейки — параметр, а не константа: при переходе на другие высоты подлежит пересмотру;
- расписание видимости кэшируется по ключу «конфигурация группировки + эпоха + версии входов и Orekit».
