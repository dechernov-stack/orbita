# ADR-007. Подвижность — статика и маршруты

**Статус:** принято (Р7)
**Решение:** модели подвижности первой очереди — статика и маршруты (треки транспорта, судов). Роуминг регуляторных зон (пересечение EU868 → RU864) не реализуется.

**Следствия:** трансграничные маршруты в модели остаются, регуляторный регион считается одним на весь трек. Для покрытия и задержки нейтрально; для ёмкости в приграничных ячейках — приемлемая погрешность Phase A. Атрибут региона у терминала уже есть, позже меняется только логика применения.
