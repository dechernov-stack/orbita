# ADR-009. QoS-профили сервисов по видам потребителей

**Статус:** принято (Р9)
**Решение:** сервис несёт не единый показатель качества, а QoS-профиль по видам потребителей (A'/B'/C'). Показатели требований (MOP) порождаются попарно «сервис × вид потребителя».

**Основание:** один сервис обслуживает разные классы терминалов с несопоставимыми критериями качества (вероятность доставки / доставка за N попыток / время реакции).

**Следствия:** гранулярность связи «сервис → требование» повышается; матрица верификации строится по парам.
