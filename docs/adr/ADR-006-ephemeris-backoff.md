# ADR-006. Эфемеридный backoff для класса B'

**Статус:** принято (Р6)
**Решение:** после N неудачных попыток на текущем КА терминал класса B' прекращает попытки и ожидает следующий аппарат по известному расписанию пролётов.

**Основание:** повторы в перегруженный канал одного КА усиливают лавину нагрузки (offered load ≫ carried load).

**Следствия:** обмен «надёжность за задержку» — вероятность доставки растёт, хвост распределения задержки удлиняется на интервал до следующего КА; качество сервиса B' связывается с числом аппаратов в плоскости (критерий баллистической оценки).
