# ADR-033. Промпт постановки — из данных, не из общих слов

**Статус:** принято (Ф-05 пачки-1 фиксов прогона)
**Контекст:** операция О2 уходила в модель с одним «входом операции». Если
инженер не вставил записку руками, промпт нёс профиль, счётчики модели и
пустую строку — генерация была холостой, а система лишь предупреждала об
этом мелким шрифтом. Полки библиотеки, класс миссии, взятые наборы и
принятый урожай разбора в промпт не попадали вовсе.

## Решение

### 1. Замысел миссии — обязательное условие, не пожелание

Паспорт несёт `mission_intent`: **для кого · что делает · где · горизонт** —
четырьмя полями либо одним связным абзацем. Замысел считается заданным,
если есть абзац или все четыре поля; трёх из четырёх недостаточно.

Без замысла генерация постановки **заблокирована с причиной** — отказом
сборки промпта («нет замысла миссии — генерация постановки даст общие
места»), а не предупреждением. Правило живёт у сборки промпта, поэтому
одинаково срабатывает на предпросмотре и на вызове модели.

Виды, которым замысел обязателен, названы в реестре видов пакетов полем
`requires_mission_intent` — перечень расширяется данными, не кодом.

### 2. Источники промпта — данными, с именами и счётчиками

Промпт операции собирается из источников, перечисленных в реестре видов
(`statement_sources`), в постоянном порядке:

| источник | что вносит |
|---|---|
| `intent` | замысел миссии |
| `class_library` | класс миссии и его полки: типовые сервисы, профили стейкхолдеров (А2), типовые риски (Б3), нормативы (Б1), термины глоссария |
| `taken` | взятые наборы Ш2 — рамкой «в проекте уже есть N — опираться, не дублировать» |
| `accepted` | принятый урожай разбора документов (Д2) — «уже принято», с именем документа |
| `prohibitions` | действующие ограничения паспорта (отменённые не идут) |

### 3. Пустой источник виден, а не исчезает

В промпте пустой источник печатается строкой «— пусто» с причиной, в
предпросмотре — той же строкой рядом с именем источника. Общие слова
вместо данных становятся невозможны по построению: инженеру видно, чего
в промпте нет и откуда это взять.

### 4. Пакетный канал не затронут

Вставка готового пакета (закрытый контур, шаг Б2 ПМИ) промпт собирает
только для журнала — замысел там не требуется.

## Приёмка

`StatementSourcesTest`: без замысла — отказ с причиной; замысел полями и
абзацем равноправны; неполный замысел замыслом не считается; источники
приходят в постоянном порядке с содержимым полок; отменённое ограничение
в запреты не идёт; пустой источник несёт счётчик 0 и пометку. На стенде:
промпт О2 несёт позиции полок, предпросмотр показывает состав, пакетный
канал вносит пакет без замысла.
