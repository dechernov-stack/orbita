# ADR-003. Межспутниковая связь — только РЧ

**Статус:** принято (Р3)
**Решение:** ISL моделируется только в РЧ-диапазоне (S/Ka). Оптические линии вне рамок.

**Основание:** нереалистичны в классе платформ 12U–100 кг (ADR-002); требуют точности взаимного наведения и заметного времени установления соединения.

**Следствия:** граф связности группировки определяется чистой геометрией (линк доступен практически мгновенно при прямой видимости); упрощается бюджет времени реакции класса C'.
