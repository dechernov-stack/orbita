# ADR-027. Связи trace, allocation и derive выводятся из документа

**Статус:** принято (Шаг 16 §3.1)

## Контекст

Связи трёх видов заводил только `ingest*` при создании объекта: `traces_up`,
`allocated_to` и `derives_from` документа превращались в записи `links`.
Правка (`Editing.update`) вызывала `objects.change` и связей не трогала.

Обычный ход работы — создал требование, потом привязал правкой — не давал
ни одной связи. Дерево оставалось плоским, матрица трассировки пустой, и
тесты этого не видели: они звали `ingest` напрямую.

Одновременно существовал второй источник — ручной `POST /links` теми же
тремя видами. Два источника одного факта расходятся молча.

## Решение

Документ — **единственный** источник связей `trace`, `allocation`, `derive`.
При каждой записи новой версии (`ingest`, правка, правка с основанием, откат)
связи пересчитываются по документу — `ReqService.syncLinks`, эталон
`spec/link_semantics.py`.

Правила пересчёта:

- ссылка исчезла из документа → связь удаляется;
- ссылка появилась → связь создаётся;
- **уцелевшая связь правится на месте, а не пересоздаётся.**
  `derivation_kind`, выставленный операцией `deriveAs`, сохраняется:
  удаление и вставка молча вернули бы `allocated` — производное требование
  стало бы распределённым и вошло бы в свёртку бюджета. Это самый дорогой
  из возможных здесь тихих сбоев;
- `POST /links` для этих трёх видов отвечает отказом 409 с объяснением;
  вид `verification` маршрут сохраняет — событие привязывается к требованию
  оттуда.

Связь `need → service` объявляется с двух сторон (`need.traces_down` и
`service.traces_up`); она удаляется, только когда её не объявляет **ни один**
из двух документов — иначе правка сервиса молча рвала бы нить, которую
нужда продолжает объявлять.

## Последствия

- Владелец связи определён: чинить трассировку значит править документ,
  а не таблицу связей.
- `ingest*` пользуются тем же `syncLinks` — входа два не бывает и при
  создании.
- Инструменты, писавшие в `/links` виды trace/allocation/derive, получают
  отказ с указанием, какое поле документа править.
